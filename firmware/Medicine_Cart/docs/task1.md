# Task 1：验证红线巡线基础

## 目标

确认 `WHEELTEC_C07A_CAR` 的 8 路灰度巡线硬件能否在本题红线、地面和实际光照下稳定工作，并确定后续巡线方案。

## 前置条件

- 底盘可正常供电、驱动电机和读取编码器。
- 已搭建一段与赛题一致的红线和地面测试区域。

## 步骤

1. 采集 8 路传感器在白底、红线、黑色边界线上的原始输出。
2. 在不同环境光、不同车速和不同横向偏移下重复采集。
3. 判断红线与地面的输出是否可稳定区分，并记录有效电平/阈值。
4. 基于现有 `Gray_Mode()` 进行低速直线和弯道巡线测试。
5. 测试丢线后的停车或搜线行为，确认不会继续盲目前进。

## 交付物

- 传感器测试记录：场地条件、原始读数、有效阈值或电平。
- 巡线方案结论：沿用现有灰度方案、调整判定逻辑，或改用其他检测方案。

## 完成判据

- 在预期光照下可稳定区分红线与地面。
- 低速通过直线和弯道时不持续偏离红线。
- 丢线时小车停车或受控搜线，不发生失控前冲。

> 若红线无法稳定识别，本任务未完成；暂停后续巡线集成，先调整硬件或检测方案。
