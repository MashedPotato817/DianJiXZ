## 现有巡线基础

小车底盘的巡线实现位于 [`../../WHEELTEC_C07A_CAR/`](../../WHEELTEC_C07A_CAR/)；后续控制工程应以其为基础复用，不直接在该基础工程中堆叠本题业务逻辑。

- [`Control/control.c`](../../WHEELTEC_C07A_CAR/Control/control.c) 的 `Gray_Mode()`：读取 8 路灰度传感器，以加权位置计算转向，并在 5ms 定时中断中参与速度闭环控制。
- [`Control/control.h`](../../WHEELTEC_C07A_CAR/Control/control.h)：包含巡线速度、转向增益、丢线搜索等参数。
- 该实现当前按黑线传感器逻辑工作；本题使用红线，必须先在实际赛道和光照下验证传感器对红线的可分辨性，再决定沿用、调整阈值或更换检测方案。

## K230 串口通信基础

K230 与 MSPM0 的接线、串口参数和链路握手以 [`../../K230_UART_Demo/`](../../K230_UART_Demo/) 为准：K230 Port1 的 IO40/IO41 分别连接 MSPM0 PB7/PB6，使用 115200、8N1；握手报文使用 `$...#` 定界。

该 Demo 已验证链路在线和心跳，但其 `DATA` 报文不携带识别结果。送药车实现时应在保留握手、超时和帧定界机制的前提下，增加“病房号 + 置信度/有效标志”的识别结果报文，并由主控进行连续稳定性确认。

## 目标

小车在药房识别目标病房号，检测药品装载后自动出发；沿红线到达指定病房门口后停车并亮红灯；药品卸下后自动返回药房，停车并亮绿灯。

基础任务应覆盖近端、中部和远端病房，且每次送达和返回时间均小于 20 秒。

## 运行状态机

```text
WAIT_TARGET
  └─ 识别到稳定病房号 ─→ WAIT_LOAD

WAIT_LOAD
  └─ 检测到药品已装载 ─→ OUTBOUND

OUTBOUND
  └─ 按目标病房完成寻径并进入门口区域 ─→ ARRIVED

ARRIVED
  └─ 停车、亮红灯；检测到药品已卸下 ─→ RETURN

RETURN
  └─ 回到药房门口且车头朝向药房 ─→ FINISHED

FINISHED
  └─ 停车、亮绿灯；复位后 ─→ WAIT_TARGET
```

任一运行状态发生失线、视觉通信超时或定位异常时，进入故障停车状态，关闭电机并记录故障原因，等待人工复位。

## 各状态职责

| 状态 | 输入 | 动作 | 退出条件 |
| --- | --- | --- | --- |
| `WAIT_TARGET` | K230 病房号识别结果 | 停车、绿灯和红灯关闭；对连续识别结果做稳定性确认 | 得到有效的目标病房号 1–8 |
| `WAIT_LOAD` | 装载检测 | 停车，保存目标病房号和对应路线 | 检测到约 200g 药品已装载 |
| `OUTBOUND` | 红线、路口/里程、目标路线 | 巡线、计数和转向，驶向目标病房 | 车头进入目标病房门口区域 |
| `ARRIVED` | 卸载检测 | 停车、亮红灯 | 检测到药品已卸下 |
| `RETURN` | 红线、路口/里程 | 按返程路线巡线并回药房 | 车头进入药房门口且朝向药房 |
| `FINISHED` | 复位信号 | 停车、亮绿灯 | 收到复位 |

## 导航与识别原则

- K230 只在药房阶段提供目标病房号；主控收到稳定结果后锁定目标，行驶中不依赖数字识别。
- 红线负责横向巡线，路口特征与编码器里程共同用于纵向定位和路径决策。
- 每个病房号映射为一条可配置的路径表，至少包含出发方向、路口序列、停车判据和返程路线。
- 到达和返回均以门口区域判据确认，不能仅依赖预计行驶时间。

## 实施与验证顺序

1. 验证红线传感器在实际场地、光照下的可用性，完成低速稳定巡线。
2. 验证 K230 对 1–8 号数字的稳定识别，并在 `K230_UART_Demo` 既有机制上增加识别结果报文和主控稳定判据。
3. 加入装载/卸载检测，验证 `WAIT_LOAD` 与 `ARRIVED` 的状态切换。
4. 建立近端病房的路线表，完成一次送达和返回闭环。
5. 扩展到中部、远端病房，验证随机编号下的路径映射和 20 秒时限。
6. 记录每次测试的病房号、运行时间、失线次数、到位误差和故障原因，作为优化依据。

## 本阶段完成判据

- 可识别任意目标病房号 1–8，并在装载后自动启动。
- 可完成近端、中部、远端三类病房的一次送达和返回。
- 到房时红灯亮且小车停止；回药房时绿灯亮且小车停止。
- 单程送达和返回均小于 20 秒，且运行过程满足赛题边界线与人工干预限制。
