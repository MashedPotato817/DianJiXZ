# Codex 任务：路口特征识别

## 目标

确定 8 路灰度传感器在路口处的输出特征，建立路口检测判据。

## 场地路口类型

| 类型 | 特征 | 位置 |
|------|------|------|
| 十字路口 | 30×30cm 正方形，红线交叉 | 十字1（病房1/2）、十字2（病房3/4） |
| T字路口 | 30×30cm，不能直行 | T字3（分叉5,7/6,8）、T字4 |

路口中心间距约 90cm（15+60+15）。

## 步骤

### 1. 十字路口传感器特征

- 小车沿红线直线通过十字路口
- 记录进入路口前、路口正中、离开路口后三个阶段 `Gray_Data[0..7]`
- 重点：路口中心处，8 路传感器的激活模式

**预期：** 十字路口红线横向和纵向都有，传感器应该全部或大部分检测到红线。

**需要回答：**
- 通过十字路口时，`black_count` 是多少？（全部 8 路激活？还是只有部分？）
- 进入/离开路口时的传感器模式变化是怎样的？
- 能否用 "全部 8 路或 ≥6 路激活" 作为路口检测条件？

### 2. T字路口传感器特征

- 小车沿红线直线接近 T 字路口（不能直行的方向）
- 记录接近 T 字路口时 `Gray_Data[0..7]`
- T 字路口：红线在横向有交叉，但没有纵向出口

**需要回答：**
- T 字路口的传感器模式与十字路口有何不同？
- 能否区分 "到达 T 字路口需要转弯" 和 "通过十字路口继续直行"？

### 3. 路口里程验证

- 用编码器累积距离，记录从出发到每个路口的实际里程
- 多次重复测试，统计里程重复性误差

**需要回答：**
- 药房 → 十字1 的编码器里程（mm）
- 十字1 → 十字2 的编码器里程
- 十字2 → T字3 的编码器里程
- T字3 → T字4 的编码器里程
- 每段里程的重复误差（±mm）

### 4. 转弯动作验证

- 在十字路口执行左转/右转
- 记录转弯过程中传感器模式变化
- 确定转弯完成的条件（线重新居中？还是转过固定角度？）

**需要回答：**
- 转弯需要转过约 90° 还是由传感器引导回到线上？
- 转弯过程中是否容易丢线？

## 交付物

1. 十字路口和 T 字路口的 `Gray_Data` 记录（至少各 3 次）
2. 路口检测判据建议（全激活阈值）
3. 各段里程及误差
4. 转弯行为建议
