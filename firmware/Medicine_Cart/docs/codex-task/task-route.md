# Codex 任务：病房路线表

## 目标

建立 8 个病房的去程和返程路线表，为主控提供可查询的路径数据。

## 场地布局

```
药房 ──90cm── [十字1] ──90cm── [十字2] ──90cm── [T字3] ──90cm── [T字4]
             左/   \右     左/   \右       左/   \右       左/   \右
           病房1  病房2   病房3  病房4    (5,7)  (6,8)    7    5
                                                       (或8  6?)
```

- 每个路口是 30×30cm 正方形，中心间距约 90cm
- 药房：起点，车头朝病房方向
- 十字1/2：可直行/左转/右转
- T字3：不可直行，左转去病房5/7，右转去病房6/8
- T字4（T字3左转后到达）：不可直行，左转去病房7，右转去病房5
- 门口虚线框在路口拐角处

## 需要确认的问题

1. T字3 右转后到达什么位置？是否也有一个 T字路口分叉到病房 6 和 8？
2. 病房 5/7 和 6/8 在 T字3 的哪一侧？左路是 5 和 7，右路是 6 和 8？
3. 药房门口有什么标识特征？虚线框？
4. 数字标号在走廊上的具体位置——贴在路口拐角处还是走廊地面上？

## 步骤

### 1. 实测里程参数

用编码器在实车上测量，重复 5 次取平均：

| 路段 | 编码器里程 (mm) | 误差 ±mm |
|------|----------------|---------|
| 药房门口 → 十字1 中心 | | |
| 十字1 中心 → 十字2 中心 | | |
| 十字2 中心 → T字3 中心 | | |
| T字3 中心 → T字4 中心（左转后） | | |
| T字3 中心 → 对面路口（右转后） | | |
| 药房门口特征 → 出发线 | | |

### 2. 建立路线表

为每个病房号填写：

| 病房 | 经过路口数 | 每个路口动作 | 最终停止条件 |
|------|----------|-------------|-------------|
| 1 | 1 | 十字1: 左转 | 拐角处虚线框 |
| 2 | 1 | 十字1: 右转 | 拐角处虚线框 |
| 3 | 2 | 十字1: 直行, 十字2: 左转 | 拐角处虚线框 |
| 4 | 2 | 十字1: 直行, 十字2: 右转 | 拐角处虚线框 |
| 5 | ? | | |
| 6 | ? | | |
| 7 | ? | 十字1:直行, 十字2:直行, T字3:左转, T字4:左转 | 拐角处虚线框 |
| 8 | ? | | |

### 3. 返程路线

- 从病房门口出发回到药房的路径
- 药房到位判据：车头投影在药房门口区域内 + 朝向药房
- 返程路线可能和去程不对称（因为门口方向）

## 交付物

1. 编码器里程实测数据表
2. 8 个病房的去程路线表（路口序列 + 动作）
3. 8 个病房的返程路线表
4. 门口到位判据（灰度特征 or 里程）

## 备注

路线表最终会编码为 `route.c` 中的数据结构，格式大致为：
```c
typedef struct {
    uint8_t intersection_count;     // 经过几个路口
    uint8_t actions[4];             // 每个路口的动作: 0=直行, 1=左转, 2=右转
    uint32_t stop_distance_mm;      // 最后一个路口后的停车里程
} WardRoute;
```
