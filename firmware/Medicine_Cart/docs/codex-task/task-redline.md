# Codex 任务：红线巡线基础验证

## 目标

确认 8 路灰度传感器能否在实际场地上稳定区分红线与白底，并确定通道映射和转向方向。

## 场地

白底喷绘布，居中有 1.5-1.8cm 宽红色电工胶带作为引导线。路口为 30×30cm 正方形。

## 步骤

### 1. 红线传感器响应

- 将小车放在红线上方，8 个传感器跨越红线
- 记录 `Gray_Raw[0..7]`（原始电平）和 `Gray_Data[0..7]`（逻辑值）
- 分别测试：红线居中、红线偏左（最左传感器在红线上）、红线偏右
- 在不同环境光下重复（自然光、顶灯）

**输出：** 红线对应高电平还是低电平？是否需要修改 `GRAY_BLACK_LEVEL`？

### 2. 通道映射

- 分别遮挡最左和最右的物理传感器
- 记录 `Gray_Data[0..7]` 中哪个通道变为 1
- 确认通道 0 对应车体哪一侧，通道 7 对应哪一侧

**输出：** 通道 0-7 分别对应物理左→右 还是 右→左？

### 3. 轮子方向确认

- **抬车测试**（轮子悬空，45mm/s）：
  - 黑线/红线在中间传感器下方 → 两轮应同速前转
  - 线偏左 → 左轮应减速/右轮加速（或反之）
  - 记录哪侧车轮加速
- 与 `Move_Z` 的符号约定对照：
  - `Move_Z > 0` → `MotorB.Target_Encoder` 增大（右轮加速）
  - 最终判断：当前正号 `Move_Z = +K*v*curvature` 是否正确

**输出：** 转向符号需要正号还是负号？

### 4. 低速直线巡线测试

- 45mm/s，直线段
- 观察车是否稳定跟随红线，不持续偏转

## 交付物

1. 红线原始读数记录（至少 3 种偏移 + 2 种光照）
2. 通道映射结论（物理左右对应关系）
3. 转向符号结论（正号 or 负号）
4. 直线巡线是否稳定

## 阻塞

此任务未完成前，不能修改 `line_follow.c` 中的 `GRAY_BLACK_LEVEL` 和 `Move_Z` 符号。
