# 智能送药小车 接线图

> 2026-07-25 | 基于 `WHEELTEC_C07A_CAR\docs\接线表.md`，仅列送药车用到的外设。

## 1. K230 ↔ MSPM0 串口

```
K230 CanMV (Port1)          MSPM0G3507
┌──────────────┐           ┌──────────────┐
│ IO40 (UART1_TX) ─────────→ PB7 (UART1_RX) │
│ IO41 (UART1_RX) ←───────── PB6 (UART1_TX) │
│ GND          ──────────── GND            │
└──────────────┘           └──────────────┘
```

| K230 | 方向 | MSPM0 | 参数 |
|------|:--:|------|------|
| IO40 (TX) | → | PB7 (RX) | 115200 8N1 |
| IO41 (RX) | ← | PB6 (TX) | 115200 8N1 |
| GND | — | GND | 共地 |

- **⚠️ K230 扩展口 5V 不可接入 MSPM0 UART 引脚**，仅接信号线和地。
- MSPM0 侧 `k230_link.c` 运行时关闭 UART1 DMA/中断，轮询 FIFO 接收。
- 协议：`$...#` ASCII 帧定界，握手 → 心跳 → `$K230,RESULT,<ward>,<conf>#`

## 2. 电机驱动（TB6612）

```
MSPM0G3507                            TB6612
┌──────────────┐                    ┌──────────┐
│ PA13 (AIN1)  ──── 左轮 IN1        │          │
│ PA14 (AIN2)  ──── 左轮 IN2        │          │
│ PB2  (PWM)   ──── 左轮 PWM ───────│  MOTO-A  │── 左电机
│ PA16 (BIN1)  ──── 右轮 IN1        │          │
│ PA17 (BIN2)  ──── 右轮 IN2        │          │
│ PB3  (PWM)   ──── 右轮 PWM ───────│  MOTO-B  │── 右电机
└──────────────┘                    └──────────┘
```

| 功能 | GPIO | 说明 |
|------|------|------|
| 左 PWM | **PB2** (TIMA1 CCP0) | 10kHz, 0-7800 |
| 左 IN1 | **PA13** | H=反转, L=正转配合 |
| 左 IN2 | **PA14** | H=正转, L=反转配合 |
| 右 PWM | **PB3** (TIMA1 CCP1) | 10kHz, 0-7800 |
| 右 IN1 | **PA16** | 同上 |
| 右 IN2 | **PA17** | 同上 |

逻辑：`Set_PWM(A, -B)` 对右轮取反（右电机物理镜像安装）。

## 3. 编码器（霍尔，13线 28:1）

```
MSPM0G3507                          MG513X 编码器
┌──────────────┐                    ┌──────────┐
│ PA26 (E1A)   ←── 左轮 A 相        │          │
│ PA25 (E1B)   ←── 左轮 B 相        │  MOTO-A  │
│ PB24 (E2A)   ←── 右轮 A 相        │          │
│ PB20 (E2B)   ←── 右轮 B 相        │  MOTO-B  │
└──────────────┘                    └──────────┘
```

| 功能 | GPIO | 中断 |
|------|------|------|
| 左轮 A 相 | **PA26** | GPIOA (优先级0) |
| 左轮 B 相 | **PA25** | GPIOA |
| 右轮 A 相 | **PB24** | GPIOB (优先级0) |
| 右轮 B 相 | **PB20** | GPIOB |

CPR = 2×13×28 = 728，GPIO 双边沿中断计数，5ms ISR 换算速度。

## 4. 8 路灰度巡线（CD4051 多路选通）

```
MSPM0G3507                         CD4051 选通器
┌──────────────┐                    ┌──────────┐
│ PA27 (AD0)   ──── 通道地址 LSB   │  AD0     │
│ PA12 (AD1)   ──── 通道地址 Bit1  │  AD1     │
│ PB16 (AD2)   ──── 通道地址 MSB   │  AD2     │── 8路红外对管
│ PB17 (OUT)   ←─── 数字输出       │  OUT     │
└──────────────┘                    └──────────┘
```

| 功能 | GPIO | 说明 |
|------|------|------|
| AD0 | **PA27** | 通道地址 LSB |
| AD1 | **PA12** | 通道地址 Bit1 |
| AD2 | **PB16** | 通道地址 MSB |
| OUT | **PB17** | 传感器输出 (1=黑线, 0=白底) |

8 路总跨距 85mm，间距 12.14mm。通道 0=最左 (-42.5mm)，通道 7=最右 (+42.5mm)。**红线响应电平待 Task 1 实测确认。**

## 5. OLED 显示屏（SSD1306）

```
MSPM0G3507                         SSD1306 OLED
┌──────────────┐                    ┌──────────┐
│ PB14 (RST)   ──── RES            │          │
│ PB15 (DC)    ──── DC             │          │
│ PA28 (SCL)   ──── SCL (时钟)     │          │
│ PA31 (SDA)   ──── SDA (数据)     │          │
│ VCC/GND      ──── 供电           │          │
└──────────────┘                    └──────────┘
```

模拟 SPI 协议。显示：任务状态、K230 链路、病房号、灰度原始值、线位置。

## 7. 未使用（送药车不接）

| 外设 | 原因 |
|------|------|
| 线性 CCD (PA9/PA22/PA27) | 巡线用 8 路灰度 |
| 蓝牙模块 (UART1 DMA) | 无蓝牙遥控需求 |
| JY62 陀螺仪 (UART1) | 未接入 |
| UART0 (PA10/PA11) | 配置为调试 printf 输出，不用作通信 |

```

K230 IO40 ────→ MSPM0 PB7

```

## 9. 电源树

```
电池 12V ──┬── TB6612 VM (电机电源 7-12V)
           ├── 降压模块 5V ──┬── MSPM0 VCC (USB/5V)
           │                 ├── OLED VCC
           │                 ├── 8路灰度 VCC
           │                 └── 编码器 VCC (3.3V or 5V)
           └── 降压模块 3.3V ─── (如需要)
```

K230 独立供电（USB-C 或电池），不与 MSPM0 共用电源。
