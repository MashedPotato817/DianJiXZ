# Task 5：完成近端病房单车闭环集成

## 目标

集成识别、装卸检测、巡线和路径表，完成近端病房的无人干预送药往返闭环。

## 前置条件

- Task 1 至 Task 4 均已完成。
- 已建立独立的送药车控制工程，底盘基础工程保持可回退。

## 步骤

1. 实现 `WAIT_TARGET → WAIT_LOAD → OUTBOUND → ARRIVED → RETURN → FINISHED` 状态切换。
2. 接入病房号锁定、装卸检测、近端路线和红绿灯控制。
3. 加入失线、通信超时、路径超时等故障停车处理。
4. 对 1、2 号近端病房分别重复测试送达和返回。
5. 记录并优化转向、速度和停车参数。

## 交付物

- 可运行的近端病房控制版本。
- 近端病房测试记录与已知问题清单。

## 完成判据

- 从识别目标到返回药房全程无需人工干预。
- 到房停车亮红灯，卸载后返回，回药房停车亮绿灯。
- 送达和返回均小于 20 秒，且不违反边界线要求。
