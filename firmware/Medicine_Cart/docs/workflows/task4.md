# Task 4：建立场地路径表与到位判据

## 目标

将赛题场地转化为主控可执行的病房路线表，确定路口、门口和药房的定位方法。

## 前置条件

- Task 1 已确定可用的红线巡线方案。
- 已取得实际或等比例场地图，并标出药房、病房、路口和门口区域。

## 步骤

1. 为病房 1–8 标记出发方向、经过路口、转向动作和门口停车位置。
2. 确定纵向定位依据：路口特征、编码器里程或二者组合。
3. 为每条路线定义到位判据，包含允许误差和超时保护。
4. 为每个目标定义返程路线和药房到位、朝向确认判据。
5. 在静态场地逐段验证路口识别和里程重复性。

## 交付物

- 病房号 1–8 的路线表。
- 路口、门口和药房的检测/里程参数表。
- 到位误差与重复性测试记录。

## 完成判据

- 任意病房号都有唯一的去程和返程路线。
- 路口和门口判据可重复触发，不依赖单纯计时。
- 定位误差在门口区域允许范围内。
