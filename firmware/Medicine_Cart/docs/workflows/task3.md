# Task 3：确定并验证装载/卸载检测

## 目标

选择并验证药品装载、卸载检测方案，使状态机可可靠进入 `OUTBOUND` 和 `RETURN`。

## 前置条件

- 明确药盒放置位置、约 200g 载荷和允许的机械结构。
- 已确定可用 GPIO、ADC 或通信接口资源。

## 步骤

1. 选择传感器方案，例如称重、行程开关、红外遮挡或其他可重复的方式。
2. 确定安装位置，避免药盒偏移、振动和车体加减速造成误触发。
3. 测试空载、约 200g 载荷、装卸过程和行驶振动下的输出。
4. 设置去抖、滤波或持续时间判据，分别给出“已装载”和“已卸载”条件。
5. 验证误触发时小车不会擅自出发或返回。

## 交付物

- 传感器选型、接线和安装说明。
- 装载/卸载判据与测试记录。

## 完成判据

- 药品放入后能稳定触发出发条件。
- 药品移除后能稳定触发返回条件。
- 行驶振动和短暂触碰不会误触发状态切换。
