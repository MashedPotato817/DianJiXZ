# Task 2：打通 K230 病房号识别结果通信

## 目标

在 `K230_UART_Demo` 已验证的 UART 链路基础上，将 K230 的数字识别结果可靠传给 MSPM0，并让主控得到稳定的目标病房号。

## 前置条件

- K230 模型可识别 1–8 号数字。
- 已按 `K230_UART_Demo` 完成 IO40/IO41、PB7/PB6、GND 接线和 115200、8N1 联调。

## 步骤

1. 保留 `$...#` 帧定界、握手、心跳和超时机制。
2. 定义识别结果字段：病房号、置信度或有效标志；无有效结果时必须有明确表示。
3. 由 K230 仅在有效识别时发送结果，避免将瞬时误检直接作为目标。
4. 主控对连续相同结果进行稳定性确认，确认后锁定目标病房号。
5. 验证链路超时、乱码和无效病房号时，主控保持停车并拒绝启动。

## 交付物

- 识别结果报文格式及示例。
- K230 发送和 MSPM0 解析的联调记录。
- 目标病房号稳定确认规则。

## 完成判据

- 对 1–8 号数字均可将正确病房号送达主控。
- 短暂误检或单帧误检不会改变已锁定目标。
- 断开 K230 或通信超时后，小车不会进入出发状态。
