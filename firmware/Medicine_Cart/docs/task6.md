# Task 6：扩展中部、远端病房并完成基础验收

## 目标

将已验证的单车闭环扩展到中部、远端随机病房，完成基础部分的完整验收。

## 前置条件

- Task 5 已稳定完成近端病房往返。
- Task 4 的 1–8 号路线表已完成实地标定。

## 步骤

1. 接入中部和远端路线，逐个验证 3–8 号病房的去程、停车和返程。
2. 使用随机目标病房号连续测试，检查目标锁定与路线选择。
3. 在接近比赛光照、载荷和场地条件下进行重复性测试。
4. 统计送达/返回时间、到位误差、失线次数和故障原因。
5. 针对超时、压线、误停和误识别问题进行参数优化，并回归测试。

## 交付物

- 近端、中部、远端完整测试记录。
- 基础任务验收结论与剩余风险清单。

## 完成判据

- 可完成近端、中部、远端三类病房的送药和返回。
- 随机设置的 3–8 号病房均能选择正确路线。
- 每次送达和返回均小于 20 秒，且满足停车指示、边界线和无人工干预要求。
