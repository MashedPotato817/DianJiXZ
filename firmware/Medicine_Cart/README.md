# 智能送药小车

2021 年全国大学生电子设计竞赛 F 题“智能送药小车”的项目资料与视觉识别资源。当前阶段先完成赛题分析和设计路线，再开展小车控制工程实现。

## 目录说明

| 目录 | 内容 | 约定 |
| --- | --- | --- |
| [`topic/`](topic/) | 赛题原文与场地示意图 | 原始题目资料，非必要不修改。 |
| [`docs/`](docs/) | 赛题分析、设计路线、接口约定和测试记录 | 方案讨论与设计文档统一写入此处。 |
| [`k230/`](k230/README.md) | K230 CanMV 病房数字识别模型与推理脚本 | 部署与使用方法见目录 README。 |
| [`mspm0/`](mspm0/README.md) | 送药车 MSPM0 主控工程 | 当前为无代码的工程占位；后续从 `WHEELTEC_C07A_CAR` 复制底盘基础后在此开发。 |

## 当前范围

- 已具备：赛题资料、K230 病房号 1–8 目标检测最优模型及推理脚本。
- 待完成：建立 MSPM0 底盘控制工程、K230 与主控通信、红线巡线、装卸检测、任务状态机和双车协同。

## 开发顺序

1. 在 `docs/` 完成赛题设计路线，明确传感器方案、状态机、导航方法和通信协议。
2. 验证 K230 数字识别、红线检测和装卸检测等关键风险项。
3. 在 `mspm0/` 中基于现有 MSPM0 差速车底盘工程建立独立控制工程，逐步接入各模块。
4. 完成单车送药往返后，再实现双车协同任务。

赛题条款和验收要求以 [`topic/`](topic/) 内资料为准；设计结论和变更原因应记录在 `docs/`，不要回写到题目资料中。
