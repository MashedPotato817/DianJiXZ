## 编译方法

### 环境要求
- **编译器**：XeLaTeX（TeX Live 2024+ 或 MiKTeX）
- **中文字体**：Fandol（TeX Live 自带，无需额外安装）

### 编译命令
```bash
# 在模板所在目录执行：
xelatex template_car.tex     # 编译小车模板（替换为你想编译的文件名）
xelatex template_car.tex     # 运行第二次以更新目录和交叉引用
```

### 如果提示缺少字体
```bash
# 检查已安装的中文字体
fc-list :lang=zh

# 如果 Fandol 不可用，将文档类中的 fontset=fandol 改为：
# fontset=windows   （Windows 系统）
# fontset=mac        （macOS 系统）
# fontset=ubuntu     （Ubuntu 系统）
# fontset=none       （使用系统默认字体）
```

## 填空指南

### 快速定位所有需要填写的位置
在编辑器中搜索以下标记即可快速跳转到所有需要填写的位置：
- `\blank` — 短文本填写位
- `\placeholder{...}` — 长文本填写位（通用模板）
- `待实测` — 等待实测数据填入

### 填写顺序建议（比赛 4 天 3 夜时间分配）
| 时间段 | 工作内容 |
|--------|---------|
| Day 1 下午 | 拿到题目后→写摘要草稿、系统方案对比、器件选型 |
| Day 2 | 硬件搭建→写第 2 章（器件、电路、控制模型公式推导） |
| Day 3 | 软件调试→写第 3 章（程序流程、状态机）+ 第 4 章（环境） |
| Day 4 上午 | 全部联调→填测试数据表、拍照片插图 |
| Day 4 下午 | 写第 5 章（成效分析、创新点）→ 审稿 → 打印装订 |

### 写作要点
1. **摘要最后写**——先写完正文再提炼摘要，保证准确性
2. **方案对比必有 ≥2 个方案**——评审加分项
3. **测试仪器必标具体型号**——如"Tektronix MDO3024 示波器"，不可笼统写"数字示波器"
4. **公式必须用 LaTeX 格式**——不要贴图片公式
5. **图、表必须有编号和标题**
6. **正文控制在 6~8 页**（8000 字以内）

## 格式要求检查清单

- [ ] A4 纸，纵向打印
- [ ] 页面上方空白 ≥ 3cm（装订区）
- [ ] 正文小四号宋体，标题可加大
- [ ] 页码在每页右下角
- [ ] 封面和正文每页**无学校名、代码、队员姓名**（仅密封纸上写）
- [ ] 摘要 ≤ 300 字，单独一页
- [ ] 图注在图下，表注在表上
- [ ] 所有表格和图片缩放后清晰可读
