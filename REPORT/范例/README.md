## 报告标准结构（7 章）

根据历年评分标准和参考模板，一份完整的技术报告应包含：

| 章节 | 名称 | 主要内容 |
|------|------|---------|
| 摘要 | 摘要 + 关键词 | ≤300 字，概括系统组成、方案、创新点、结果 |
| 1 | 设计方案与工作原理 | 方案对比论证、系统框图、工作原理 |
| 2 | 核心部件与电路设计 | 关键器件选型、电路原理、控制模型与参数 |
| 3 | 系统软件设计分析 | 程序流程图、状态机、关键模块说明 |
| 4 | 竞赛工作环境条件 | 软件环境、硬件平台、调试条件 |
| 5 | 作品成效总结分析 | 测试方案、实测数据、误差分析、创新点 |
| 6 | 参考资料及文献 | 引用格式参考文献列表 |
| 7 | 附件材料 | 源代码清单、电路图、检查清单 |

## 格式要点（评审扣分项提醒）

- ⚠️ 正文 **A4 纸 6~8 页**，8000 字以内
- ⚠️ 页面上方必须留出 **3cm 以上空白**（装订区），**空白内不得有任何文字**
- ⚠️ 封面及正文**每一页不得出现学校名、代码、姓名**，否则取消评审资格
- ⚠️ 测试数据必须标注**具体仪器型号**（如"Tektronix MDO3024 示波器"），不可笼统写"数字示波器"
- ⚠️ 每个模块至少给出 **2~3 个方案对比**，说明选择理由
- ⚠️ 数学公式按 **LaTeX 格式**呈现
- ⚠️ 图表须有编号和标题，图注在图下，表注在表上

## 评分参考框架

| 评分项 | 分值 |
|--------|------|
| 方案设计与论证 | ~6 分 |
| 理论分析与计算 | ~6 分 |
| 电路与程序设计 | ~4 分 |
| 测试方案与测试结果 | ~4 分 |
| 格式规范性 | ~2 分 |
| **设计报告总分** | **~20~22 分** |

> 注：设计报告为独立评分项。作品评测（基本要求 + 发挥部分）占另外 100 分。报告分虽少但往往决定奖项等级的关键差距。
