# K230 小球视觉模块

本目录存放 H 题 K230 视觉端的源码、模型、部署脚本、标定数据和串口协议样例。它的职责是从相机图像中稳定输出小球沿摆杆方向的位置，不直接控制底盘或舵机。

项目级入口见 [../README.md](../README.md)，主控接口与验收顺序见 [../topic/software_workflow.md](../topic/software_workflow.md)。

```text
k230/
├── README.md

```

## 视觉端输出要求

主控需要的最小信息为：

| 字段 | 含义 |
| --- | --- |
| `x_mm` | 小球相对摆杆中心的沿杆位置，单位 mm；右正左负 |
| `valid` | `1` 表示当前帧可靠检测到小球，`0` 表示丢球、遮挡或置信度不足 |
| `seq` 或 `timestamp_ms` | 递增帧序号或时间戳，用于主控判断延迟和丢帧 |

首轮联调建议使用容易抓包的 ASCII 帧：

```text
$K230,BALL,<x_mm>,<valid>,<seq>#
```

这只是建议格式，不是已冻结协议。开始 MSPM0 解帧前，必须在 `protocol/` 中写入最终帧格式、字段范围、校验方式、帧率和超时策略。

## 开发顺序

1. 在 **K230 实机** 确认 CanMV 固件、相机驱动和目标视觉 API 可用。
2. 完成球心检测：静态球、缓慢移动球、不同光照和背景均要采集验证样例。
3. 完成标定：把像素坐标换算为相对杆中心的毫米坐标，并记录相机安装位置和误差。
4. 添加时序滤波与有效性判断，避免单帧误检直接传给主控。
5. 输出固定格式 UART 帧并保留抓包样例。
6. 接入 MSPM0 后验证帧率、延迟、超时和遮挡处理。

## 验收标准

- 连续 60 秒输出位置数据，帧格式无丢字节、无字段越界；
- 遮挡或丢球时在约定超时内输出 `valid=0` 或停止有效帧；
- 在摆杆全行程内，毫米坐标方向正确，标定误差满足后续 1 cm 控球目标的预算；
- 主控收到无效或超时数据时能安全停车、舵机回中位。

## 注意事项

- `cv_lite` 属于目标 K230 CanMV 固件提供的视觉扩展，不能用桌面 Python 环境的导入结果判断设备支持情况。
- 若采用 `cv_lite`，先在板端运行最小导入探针；若不可用，记录固件版本和错误，再决定升级固件或使用其他实现。
- 不把模型文件、大型原始视频或构建缓存直接提交到 Git；只提交可复现的部署配置、必要的小样例和下载/生成说明。
