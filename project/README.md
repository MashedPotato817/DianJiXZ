# 2026 TI 杯 H 题：车载平衡滚球运动控制系统

本目录是 H 题的唯一交付工程。目标是在 MSPM0G3507 差速底盘沿黑色闭环路线行驶时，使用 K230 相机测量摆杆内小球位置，并通过摆杆舵机实现静止和行驶过程中的位置保持。

## 当前状态

- 底盘工程：已从 `WHEELTEC_C07A_CAR` 建立独立 MSPM0 工程，保留电机、编码器、灰度巡线、OLED 与 5 ms 控制中断。
- 巡线实测：当前实验基线为 `bcf8876`；小车可以循线，但直线仍左右摆动，此前还出现过顿挫和纠偏时单轮间歇停转，尚未达到可合并 `main` 的稳定程度。
- 软件骨架：UART2 K230 ASCII 收包与超时逻辑已接入；舵机仍只有角度抽象，小球 PD 增益为零，H 题任务模块目前只有状态存取骨架。
- 本地构建：`project/mspm0` 已用 Keil 编译通过 `0 Error(s), 0 Warning(s)`。
- 未验证内容：K230 小球识别、UART2 实物收包、舵机 PWM 输出、静止控球与行驶控球均待硬件联调；不能据此宣称完成题目指标。

## 系统数据流

```text
灰度传感器 ──> MSPM0 巡线/速度闭环 ──> TB6612 ──> 左右轮
                                      │
K230 相机 ──> UART2 小球位置帧 ──> MSPM0 小球控制 ──> 摆杆舵机
```

主控以 5 ms 为底盘控制周期。当前 K230 最小协议为
`$K230,BALL,<x_mm>,<valid>,<seq>#`，使用 UART2（PB18 RX、PB17 TX，
115200）。视觉超时保护已在链路层实现，但任务状态机和舵机硬件输出尚未接入；
当前灰度全白时底盘会沿最后一次有效轨迹继续行驶，而不是进入完整系统故障状态。

## 开始开发

### MSPM0

1. 用 Keil uVision5 打开 `mspm0/keil/empty_LP_MSPM0G3507_nortos_keil.uvprojx`。
2. 选择目标 `MSPM0G3507_Project` 后编译。
3. 引脚或外设变更只在 `mspm0/empty.syscfg` 中通过 TI SysConfig 修改并重新生成 `ti_msp_dl_config.c/h`；禁止手改生成文件。
4. 首次硬件验证按“电机/编码器 → 灰度巡线 → K230 UART → 舵机 → 静止控球 → 行驶控球”的顺序进行。

### K230

1. 阅读 [k230/README.md](k230/README.md)，确认相机、固件和串口接线。
2. 先在 K230 实机验证相机和视觉 API，再做小球识别与毫米标定。
3. 与主控共同冻结数据帧格式后，才实现真实 UART 收发和闭环联调。

## 未冻结的硬件输入

以下信息未确认前，不修改舵机引脚或重分配当前 UART：

- 舵机型号、信号引脚、供电、机械中位、可用角度、最小/中位/最大脉宽；
- K230 当前软件路由为 UART2（PB18 RX、PB17 TX、115200）；仍需确认实物交叉接线、共地和 K230 端口配置；
- 摆杆为单自由度或双自由度；当前主控只预留一维小球位置控制；
- K230 输出的小球坐标系、单位、有效性条件和帧率。

## 当前接手重点

当前工作分支为 `feat/motor-driver`，不要在直线摆动未解决前合并到 `main`。
接手底盘巡线时按以下颗粒度工作：

1. 先读 [mspm0/README.md](mspm0/README.md) 的“底盘巡线实测状态”，再读
   `mspm0/Control/control.c` 和 `control.h`；旧巡线文档只作为历史试验记录。
2. 当前目标只是在 `r=0.4~0.5 m` 操场形黑线赛道上实现连续、稳定巡线；
   `105 mm/s` 是排查速度，不满足题目单圈 `20 s` 要求。
3. 下一轮修改前同步记录 `G/P/Z`、左右目标速度、实际速度和 PWM，先判断摆动来自
   巡线目标还是速度闭环；不要同时修改灰度权重、转向增益、PI 和速度。
4. 代码、构建和实车证据分开陈述。当前已确认“可构建、可循线、仍摆动”，
   尚未确认全白续转、连续多圈和计时达标。

## 协作与提交

- 一个可独立验证的能力对应一个提交，例如 `feat: 接入摆杆舵机 PWM 输出`。
- 提交源码、Keil `.uvprojx`、`empty.syscfg`、重新生成的 `ti_msp_dl_config.c/h`、启动文件和链接脚本。
- 不提交 `Objects/`、`Listings/`、`.metadata/`、`.uvoptx` 等本机生成物。
- 每次实车测试记录提交号、固件版本、K230 版本、控制参数、场地条件、现象与原始数据位置；软件结果与硬件实测结果分开陈述。
