# 2026 TI 杯 H 题：车载平衡滚球运动控制系统

本目录是 H 题的唯一交付工程。目标是在 MSPM0G3507 差速底盘沿红色闭环路线行驶时，使用 K230 相机测量摆杆内小球位置，并通过摆杆舵机实现静止和行驶过程中的位置保持。

- 未验证内容：K230 小球识别、K230 UART 实收、舵机 PWM 输出、静止控球与行驶控球均待硬件联调；不能据此宣称完成题目指标。

## 系统数据流

```text
灰度传感器 ──> MSPM0 巡线/速度闭环 ──> TB6612 ──> 左右轮
                                      │
K230 相机 ──> 小球位置 UART 帧 ──> MSPM0 小球控制 ──> 摆杆舵机
```

主控以 5 ms 为底盘控制周期。K230 小球位置应以毫米为单位、带有效标志和帧序号/时间戳发送；视觉超时、巡线失效或急停时，任务状态机必须停车并将舵机回到安全中位。

## 开始开发

### MSPM0

1. 用 Keil uVision5 打开 `mspm0/keil/empty_LP_MSPM0G3507_nortos_keil.uvprojx`。
2. 选择目标 `MSPM0G3507_Project` 后编译。
3. 引脚或外设变更只在 `mspm0/empty.syscfg` 中通过 TI SysConfig 修改并重新生成 `ti_msp_dl_config.c/h`；禁止手改生成文件。
4. 首次硬件验证按“电机/编码器 → 灰度巡线 → K230 UART → 舵机 → 静止控球 → 行驶控球”的顺序进行。

### K230

1. 阅读 [k230/README.md](k230/README.md)，确认相机、固件和串口接线。
2. 先在 K230 实机验证相机和视觉 API，再做小球识别与毫米标定。
3. 与主控共同冻结数据帧格式后，才实现真实 UART 收发和闭环联调。

## 未冻结的硬件输入

以下信息未确认前，不修改舵机和 K230 的 SysConfig 引脚分配：

- 舵机型号、信号引脚、供电、机械中位、可用角度、最小/中位/最大脉宽；
- K230 与 MSPM0 的 UART 对应关系、波特率和共地状态；
- 摆杆为单自由度或双自由度；当前主控只预留一维小球位置控制；
- K230 输出的小球坐标系、单位、有效性条件和帧率。

## 协作与提交

- 一个可独立验证的能力对应一个提交，例如 `feat: 接入摆杆舵机 PWM 输出`。
- 提交源码、Keil `.uvprojx`、`empty.syscfg`、重新生成的 `ti_msp_dl_config.c/h`、启动文件和链接脚本。
- 不提交 `Objects/`、`Listings/`、`.metadata/`、`.uvoptx` 等本机生成物。
- 每次实车测试记录提交号、固件版本、K230 版本、控制参数、场地条件、现象与原始数据位置；软件结果与硬件实测结果分开陈述。
