## ① 结论摘要：第 3 项可行算法

### 1.1 社区主流的控制架构共识

对中文社区（2017 板球/滚球系统 → 2026 车载平衡滚球 H 题）的同类型题目检索后，**最有效的控制架构是"位置外环 + 角度内环"的串级控制（双闭环）**，而非单环位置 PD。理由与证据：

- **DFRobot 球杆项目**（`mc.dfrobot.com.cn/thread-29023`）是离本系统最接近的直接工程实践：内环（角度环）PD（P=80、D=80）加速度前馈 `15×observed_speed`，外环（位置环）PD（通过观测器取速度项），作者明确说明"被控系统本身含有积分环节，不需要 I；单纯 P 控制极点在 y 轴属临界稳定，必须加 D 把极点配到左半平面"。
- **自动控制课程设计**（`renrendoc.com/paper/206694637`）给出经典串级参数整定结果：内环角度环用"微分先行 PD"（Kp=29、Td=0.8，超调<5%、调整<3s），外环位置环用"微分先行 PID"（Kp=3.1、Td=2.01、Ki=0.3，超调 3.75%、上升 1.78s）。
- **学术论文《双变量串级 PID 板球控制系统的设计与实现》**（万方 `kxjsygc202104030`，北大核心）结论：位置+速度双变量串级 PID 相比单环 PID"调节时间短、超调量小、误差小、抗干扰好"。原理是**外环输出经限幅后作为内环（速度/角度）目标**，等效于限制小球最大速度 → 大行程（+5 到 -5 共 10cm）不冲过头。

**对本系统的落地建议**：本系统没有角度反馈内环，舵机本身就是"角度执行器"（PWM 直接对应角度），因此最现实的升级路径是——

1. **保留/强化位置环的 D 项**，这是消除过冲最直接的社区共识手段；
2. **对位置环输出（舵机目标角度）做限幅 + 斜坡限速**，即用软件实现"速度规划"，等效于串级的思想：行程远时限制摆杆角速度上限，让小球接近匀速运动，从根上压住惯性过冲；
3. **积分（I）必须加但必须抗饱和**，社区一致认为 I 是消除静摩擦稳态误差的手段，但"误差大时积分饱和会引发过冲"，故普遍采用**分段 PID（误差大 → 纯 PD，接近目标 → 才启用 I 微调）**；
4. 若追求更高性能再加**设定值前馈**（向目标侧预倾斜）与**观测器/滤波速度项**（替代直接微分，抑制视觉噪声）。

### 1.2 直接针对"0→+5→-5 折返"的两种社区路线

| 路线 | 做法 | 优点 | 缺点 | 社区案例 |
|---|---|---|---|---|
| **开环三动作（实测 2s）** | ①向右倾→钢球加速向 +5；②向左倾→减速并反向；③向右倾→减速刹停 | 实现极简、快（2~3s 内完成） | 精度依赖角度标定与桌水平，对摩擦/地面变化鲁棒性差 | B站"第三问钢珠位置控制效果展示 2 秒内完成"（`BV1bb3s6SEie`） |
| **闭环位置 PD/串级 + 限速** | 视觉反馈位置 → PD → 舵机角度，输出限幅/斜坡限速 | 稳态精度高、抗扰、符合题目"稳定"要求 | 调参工作量大、易过冲 | 2017 板球全国二等奖（PD）、DFRobot（串级 PD） |

**结论**：第 3 项对"±5cm 处误差 ≤1cm"有明确精度要求，且要求"稳定"，社区经验表明**纯开环的稳态精度不足以稳定在 ±5cm 处 1cm 内**（2017 板球 PD 单环实测稳态误差就有 ~13.5mm）。因此推荐**保留闭环 PD/串级路线为主，借鉴开环路线做"阶段规划"**：把 10cm 大行程拆成"加速段 + 匀速段 + 减速逼近段"，减速段用闭环 PD 精调，接近目标启用 I + 静摩擦补偿。这正好兼容现有状态机（ACCEL→RUN→BRAKE→PASS→CAPTURE），只需在 BRAKE/CCAPTURE 段补上"限速 + 抗饱和 I + 摩擦微补偿"。

### 1.3 消除过冲的三板斧（社区共识）

1. **微分阻尼**：所有方案都靠 D 项刹车；"球冲出板面 = 刹车不够 = 调大 D"。
2. **输出限幅 / 限速**（串级或软件斜坡）：大行程不过冲的根本。
3. **积分抗饱和 / 分段启用 I**：接近目标才用 I 消除静差，避免误差大时积分堆积导致过冲。

### 1.4 处理静摩擦 / 卡球

- **机械层（社区首选）**：换更光滑的金属球、更平整的杆面、轴承传动；DFRobot 直言其"追踪变化信号时震荡或卡死，主因是滑动物体与横杆静摩擦大，另换更平横杆"。
- **控制层**：① 接近目标且位置停滞时，叠加**微小高频抖振/颤振信号（dither）**克服静摩擦（PD 型模糊控制器做法）；② 摩擦补偿器 / 摩擦观测（学术）；③ 把摩擦当"总扰动"由 ADRC/ESO 估计补偿（学术）；④ 死区补偿：误差 < 阈值时输出一个"突跳"最小脉宽，打破静摩擦。

### 1.5 视觉检测实践经验与精度

- **颜色方案**：社区实测"白球 + 黑板/深色杆"比"黑球 + 白板"可靠（黑球反光、影子干扰）；PPR 水管凹槽内钢球**只能灰度识别**（钢球难上色），需自适应阈值 + 闭运算 + 面积/圆形度联合筛选 + 中值滤波。
- **标定必须做**：像素→实际坐标需比例 + 零点偏移标定（已知尺寸参考物或棋盘格），2017 板球要求 X/Y 反馈误差 ≤±0.5mm；本系统 6mm 中心偏移未标定是明确的精度损失，必须补标定。
- **性能参考**：K230 钢球识别可达 60fps、误差 <2mm；640×480 下 30fps 足够；OpenMV QQVGA 27~28fps；建议降分辨率换帧率（1280×960→640×480，帧率 8→30fps，精度几乎不降）。
- **滤波**：对坐标做中值/卡尔曼滤波，丢弃无效帧 (0,0)，否则 PID 输出突变导致舵机乱打角。

### 1.6 常见坑（直接影响本系统）

- 舵机死区（典型 ±0.4%）、滞环（±2%）、回差（≤4us）：死区太小会抖舵，太大有稳态误差；舵机在平衡位附近**扭力不足会自激振荡**（2017 板球实践：调 PID 无效，需缩短力臂/换大扭矩舵机）。
- 直流电机换向死区会造成抖动，社区换步进电机解决；但步进 PWM 频率 >10kHz 会失步。
- 视觉延迟/帧率：连 IDE 调试会掉帧，脱机参数需重调；摄像头支架不稳坐标漂移。
- 搬运后摄像头位置变化必须重新标定。
- 电源：舵机大电流需与 MCU 隔离供电，注意纹波。

## ③ 方案归纳：社区共识与分歧点

### 3.1 社区共识（可放心采用）

1. **控制架构**：位置环 + 角度/速度内环的串级控制最优；无内环时也要用"输出限幅 + 斜坡限速 + 强 D"模拟其效果。大行程不过冲的关键是**限速**而非单纯调 D。
2. **PID 整定顺序**：先 P（让系统出现临界震荡）→ 再 D（刹车稳定）→ 最后才考虑 I（消静差），且**逐轴/逐方向单独整定**；PID 放定时器中断（10~50ms）而非串口中断。
3. **静摩擦**：机械优先（光滑球 + 平面 + 轴承），控制兜底（I 消静差 + 抗饱和 + 接近目标时微抖振/死区补偿）。
4. **视觉**：高对比度颜色方案（白球黑背景）；灰度/色块 + 面积/圆度筛选 + 中值/卡尔曼滤波；**必须做像素→实际坐标标定（含中心偏移）**；降分辨率换帧率（640×480@30fps 足够）；无效帧 (0,0) 必须丢弃。
5. **消除过冲**：D 阻尼 + 输出限幅/限速 + 积分抗饱和（分段启用 I）三件套，社区无争议。
6. **机械决定上限**：几乎所有 2017 板球经验帖反复强调"结构搭不好，软件怎么写都没用"；2026 H 题更被定性为"重结构、轻代码"。

### 3.2 社区分歧点（需结合本系统取舍）

| 分歧 | 方案 A | 方案 B | 对本系统的建议 |
|---|---|---|---|
| 执行机构 | 舵机（MG996R/HMG996，简单、扭矩大但存在死区/回差/自激） | 42 闭环步进电机（无换向死区、可编码器闭环，但重、贵、需防失步） | 已用舵机，保留；注意平衡位扭力自激问题（缩短力臂/换大扭矩），用软件斜坡抑制抖舵 |
| 第三问实现 | 开环三动作 2s 完成（快、依赖标定） | 闭环 PD 精调（稳、需调参） | 保留闭环为主 + 借鉴开环的"阶段规划"（加/匀速/减速逼近） |
| 位置检测 | 摄像头视觉（主流、可闭环、有延迟） | ToF/电位器/电阻屏（低延迟、精度高、工程量小） | 已有 K230 视觉，够用（误差 <2mm 可行）；补标定与滤波 |
| 非线性处理 | 模糊控制/模糊 PID（不依赖模型、鲁棒） | ADRC/ESO（估计总扰动补偿） | 二选一作为进阶项；先做扎实的 PD + 限速 + 抗饱和 I + 摩擦微补偿，时间够再上模糊 |
| 微分实现 | 直接差分（简单、噪声大） | 观测器/滤波后微分（平滑、无漂移） | 视觉噪声大，建议滤波后再取差，或做一阶惯性滤波的"伪微分" |
| 视觉标定 | 简化比例 + 零点偏移（快） | 张正友单目标定 + 畸变校正（准） | 先做简化标定把 6mm 中心偏移消掉，实测精度不足再上完整标定 |

### 3.3 对本系统第三项的具体行动清单（由调研归纳）

1. **先标定视觉**：在摆杆中心 O 放钢球，记录视觉坐标作为零点偏移；再在 ±5cm 处实测像素比例，至少做"比例 + 零点"线性标定，消除 6mm 偏移（这是当前 1cm 误差预算内最大的一笔已知损失）。
2. **位置环升级**：现有 PD 保留，补上——① 输出限幅 + 斜坡限速（每周期角度增量上限，等效限角速度）；② 接近目标（如 |e|<1.5cm）启用 I（小增益 + 抗饱和限幅）；③ 视觉坐标过中值/低通滤波，丢弃 (0,0) 帧。
3. **消除过冲**：把 0→+5→-5 拆为三段（加速、匀速、减速逼近），减速段收 D，行程控制在"宁少勿多"（先不冲过目标，靠 I 慢慢磨到 1cm 内），因为 5s 预算宽裕（社区 2~3s 即可完成，留 2s 冗余收敛）。
4. **静摩擦补偿**：CAPTURE 段若检测到"目标未到且位置停滞"，输出一个固定小幅"抖振/突跳"打破静摩擦；机械上确认 PPR 凹槽内壁平整、无焊点/毛刺。
5. **参考 B 站开源**：`gitee.com/linsen06/2026diansaikaiyuanqingdane`（H 题图传/机械开源）与 Charmve/BallPlate 源码（PD 结构可直接对照）。
