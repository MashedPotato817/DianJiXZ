## 一、四路调研的高度共识（可直接采用）

### 共识 1 · 控制架构：串级最优，但本系统舵机内部位置环已可当"角度内环"
- GitHub 与中文社区一致：球杆/板球定点的标准结构是 **位置外环 PD → 目标角度 → 角度内环 → 执行器**（轮趣参考：位置环 50Hz Kp=0.2/Kd=0.2/Ki=0 + 角度环 100Hz Kp=8）。
- 本系统没有摆杆角度传感器，但**舵机自身是内部位置闭环（带宽约 5~10Hz）**，等于内环已存在——位置外环输出的"目标舵机角度偏移"就是串级。**缺的只是摆杆实际角度的测量**（用于校正 trim 与回差）。
- 结论：短期不新增传感器，把现有 PD 输出解释为"相对平衡角的舵机偏移"，配合限幅即可。加装角度传感器（电位计/编码器/陀螺仪）列为可选升级。

### 共识 2 · 过冲根因：D 阻尼不足 + 带宽相对 85ms 视觉延迟过高
- 数值证据（03 报告）：现 Kp=0.24°/mm → 闭环 ωn≈5.4 rad/s；85ms 视觉延迟引入约 **26° 相位滞后**，叠加双积分器本身的 -180°，相位裕度极低 → 过冲与 ACC/PASS 极限环。
- 开源对比（01 报告）：轮趣位置环 Kd/Kp 比值 = **1.0**，本系统仅 **0.167**；多个开源项目明确"球出界就把 D 调大"。
- 社区经验（02 报告）：**大行程不过冲的根本是限速**，比单纯调 D 更有效。
- 结论：**降闭环带宽**（Kp 从 0.24 降到 ~0.01~0.03°/mm，ωc 压到 1~1.5 rad/s）+ **加强 D 阻尼**（Kd/Kp ≥1）+ **输出限幅/斜坡限速**。

### 共识 3 · 静摩擦/死区：条件积分 + 踢动 + trim 自校准，而非加大 Kp
- 死区量化（03 报告）：摆杆等效死区 ≈ **1.2° 摆角 ≈ ±5mm 位置误差**（Kp=0.24 时），正好卡在 1cm 指标内、余量极小。
- 手段（四方一致）：
  1. **小积分 + 抗饱和**（clamping/条件积分：误差大时纯 PD，接近目标才启用 I；积分限幅）——milind220 的 I 门控、Mohamed-Hawas 的积分钳位、DFRobot 的"被控对象含积分环节不需要 I"三类做法。
  2. **定点踢动（kick）**：`|e|>5mm 且 |v|<10mm/s` 且冷却期内，输出 θ_kick=±1.5~2° 持续几个周期，把现有 ACCEL"制度化"为限频脉冲。
  3. **trim 上电自校准**：放球到机械中心读视觉 0 点，或统计 θ_cmd 稳态均值，写 Flash（复用已有标定持久化）。
  4. 机械层优先：确认 PPR 凹槽内壁光滑、无毛刺；"换更重的球/更光滑导轨"是开源社区解决静摩擦的硬件捷径。

### 共识 4 · 5s 时间预算极充裕，"跑"不是问题，"停得准"才是
- 理论（03 报告）：双积分器时间最优 bang-bang 100mm 仅 **0.57s**；梯形速度规划（a_max≈400mm/s²、v_max≈160mm/s）约 **1.4s** 走完，余 3.5s 收敛。
- 实测（02 报告）：2026 H 题有队伍用开环三动作 **2s** 完成第三问。
- 结论：时间约束几乎不构成压力；压力全在稳态精度与不超时。

### 共识 5 · 视觉：弃霍夫圆改 blob 亚像素质心 + 补标定 + 提帧率
- **换算法**（04 报告）：霍夫圆输出整数圆心、无亚像素、小圆（半径~9px）脆弱，正是光照敏感与偏移的根源；改用 `find_blobs()` 阈值分割 + `cxf/cyf` 亚像素质心，K230 上快数倍、随机误差可压到 0.1px 以下（≈0.05mm）。
- **6mm 偏移根因**（04 报告）：映射中心像素 160.365 与机械中心偏差约 **-10.4px**；用"球放机械中心反校"改为约 170.7，或做 **3~5 点最小二乘标定**（利用刻度线），可压到 <1mm。
- **精度预算**（04 报告）：0.54mm/px、球径 18.5px，±1cm 要求（按 ±5mm 裕量）在像素上毫无压力；瓶颈是系统误差而非随机误差。
- **帧率**（04/02 报告）：灰度 + 窄 ROI + find_blobs + 关显示可到 30~60Hz；16Hz 下靠 EMA 平滑 + 一阶预测/Kalman 补偿延迟。K230 钢球识别实测可达 60fps、误差 <2mm。

## 二、针对第 3 项的推荐实现组合（给修复 Agent 的参考）

> 以下为调研归纳的**文档级建议**，非代码改动。按投入/收益排序。

| 层 | 做法 | 解决痛点 | 依据报告 |
|---|---|---|---|
| **V1（必做）** | 视觉改用 `find_blobs` + `cxf` 亚像素质心；窄 ROI；关自动增益/白平衡 | 检测不稳、精度 | 04 |
| **V2（必做）** | 5 点标定（利用刻度线），线性/二次最小二乘，消除 6mm 中心偏移；目标视觉误差 ≤2~3mm | ±1cm 指标 | 04 / 02 |
| **V3（强烈建议）** | 位置坐标 EMA 平滑 + 丢 (0,0) 无效帧；必要时 Kalman 预测 | 视觉噪声/延迟 | 04 / 02 |
| **C1（必做）** | 位置环降带宽：Kp 0.24 → ~0.01~0.03°/mm（ωc≈1~1.5rad/s），Kd 按 Kd/Kp≈1 配，D 项 2Hz 低通 | 过冲、极限环 | 03 / 01 |
| **C2（必做）** | 梯形速度规划参考轨迹（a_max≈400mm/s²、v_max≈160mm/s）+ 前馈，替代纯状态机硬冲；拆"加速/匀速/减速逼近"三段 | ≤5s、无过冲 | 03 / 02 |
| **C3（强烈建议）** | 小积分 + clamping 抗饱和（接近目标才启用 I，限幅 ±0.8°）+ 定点踢动（|e|>5mm 且 |v|<10 冷却 300ms，θ_kick=±1.6° 20ms） | 静摩擦死区 ±5mm | 03 / 01 |
| **C4（强烈建议）** | trim 上电自校准（复用 Flash 标定），消除 1.2° 平衡角偏差 | 驻留误差 | 03 / 02 |
| **C5（可选）** | 状态观测器（双积分模型 5ms 预测 + 16Hz 校正，Lp≈0.4/Lv≈0.08）做延迟补偿 | 反馈跳变/延迟 | 03 |
| **C6（可选）** | 加摆杆角度测量（电位计/编码器/陀螺仪）做真串级 | 进一步压误差 | 01 / 03 |
| **M1（机械核查）** | PPR 凹槽内壁光滑无毛刺、球径/表面、舵机平衡位扭力（防自激） | 静摩擦、自激 | 02 / 01 |

**推荐的优先实施顺序**：V1→V2→C1→C2→C3→V3/C4，先做确定性高的视觉标定与控制降带宽，验证不振荡后再逐步放开。

## 四、与现有实现的对齐与差异

| 现有实现（`project/mspm0`、`project/k230`） | 调研推荐 | 差异 |
|---|---|---|
| `find_circle_center`（cv_lite 霍夫圆，r 6~45px） | `find_blobs` + `cxf` 亚像素质心 | 换算法；半径范围过宽 |
| `IMAGE_CENTER_X=160.365`（三点临时标定） | 5 点标定 + 中心反校（≈170.7） | 消除 6mm 系统偏移 |
| `BALL_ROI=(0,90,320,55)` | 收窄到 ~40px 高 + find_blobs | 提帧率 |
| 位置 PD：Kp=0.24/Kd=0.040（Kd/Kp=0.167） | Kp≈0.012、Kd/Kp≈1、D 滤波 2Hz | 降带宽、加强阻尼 |
| 状态机 ACCEL→RUN→BRAKE→PASS→CAPTURE | 降带宽后简化为"逼近+驻留"两态 + 轨迹整形 | 结构可简化 |
| 无积分（Ki=0） | 条件积分（接近目标启用、抗饱和） | 补静摩擦消除 |
| trim 学习近关闭 + `BALL_CAL_ENABLE=0` | trim 上电自校准（复用 Flash 标定） | 恢复校准路径 |
| 16Hz 有效帧率 | 30~60Hz（find_blobs+关显示） | 提帧率 + EMA/Kalman |

## 五、关键参数初值汇总（供整定起点，非定值）

来自 03/04 报告，需按实机回差、舵机动态、摩擦实测缩放：

```
系统增益  a_θ ≈ 122 mm/s²/deg（1° 摆角 → 122mm/s²）
位置环    ωc ≈ 1~1.5 rad/s，ζ ≈ 0.7~0.9
          Kp ≈ 0.012 °/mm（现 0.24 的 1/20），Kd ≈ 0.016 °/(mm/s)
          Ki ≈ 0.0003 °/(mm·s)，限幅 ±0.8°（仅接近目标启用）
D 低通    2Hz 一阶
轨迹      a_max=400mm/s²（≈3.3°）、v_max=160mm/s → 100mm 约 1.4s
踢动      |e|>5mm 且 |v̂|<10mm/s 且冷却 300ms → θ_kick=±1.6° 持续 20ms
观测器    Lp≈0.4、Lv≈0.08（Kalman 按位置噪声 ±1mm 调 q/r）
视觉      find_blobs 阈值按实测光照标定，关自动增益/白平衡
          标定目标：RMSE≤1mm、max|ε|≤3mm、重复性 std≤0.1px
```
