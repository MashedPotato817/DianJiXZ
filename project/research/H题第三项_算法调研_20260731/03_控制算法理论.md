# H题第三项「+5cm⇄-5cm 折返定点」控制算法理论调研

> 日期：2026-07-31
> 适用对象：MSPM0G3507（5ms 控制周期）+ K230 视觉（~16Hz 有效帧率，位置噪声 ±1~2px≈±1mm）+ 舵机驱动摆杆（无摆杆角度反馈内环）
> 指标：运行时间 ≤5s；±5cm 处最大误差绝对值 ≤1cm

---

## ① 结论摘要（推荐算法组合）

针对「舵机 + 摄像头、低帧率、无角度内环、静摩擦明显」的系统，单一 PD + 状态机并非最优。**推荐组合如下（按优先级）**：

1. **基于模型的离散状态观测器（Kalman/Luenberger，200Hz 运行）**
   用摆杆倾角输入 + 双积分器模型，在 5ms 控制周期上对小球位置/速度做帧间估计与延迟补偿，把"16Hz 带延迟的粗反馈"变成"200Hz 连续光滑的细状态"。这是性价比最高、改动最小的一步，直接缓解痛点②③。
2. **位置环降带宽 + 适量阻尼（ωc≈1~1.5rad/s、ζ≈0.7~0.9）**
   现 Kp=0.24°/mm 对应 ωn≈5.4rad/s，相对 85ms 反馈延迟过激进（相位滞后≈26°），是过冲与 ACC/PASS 极限环的主因。建议 Kp 降到 ≈0.01~0.03°/mm、Kd≈0.01~0.03°/(mm/s)，把闭环带宽压到 0.2~0.3Hz 量级。
3. **设定点整形 / 梯形速度规划（快速定点核心）**
   +5→-5 的 100mm 移动理论上 1s 内即可走完，瓶颈在"停下"，不在"跑得快"。用带加速度/速度上限的参考轨迹发生器（梯形速度剖面 + 前馈），配合 P 跟踪，既满足 ≤5s 又消除过冲。
4. **静摩擦/死区补偿：小积分(带抗饱和) + 定点"踢动"(kick) + 上电 trim 自校准**
   静摩擦造成的死区≈1.2° 摆角 ≈ ±5mm 位置误差。用小积分（clamping anti-windup）或阈值 kick 越过死区，并在启动时自动校准舵机 trim 零点。
5. **保留或简化状态机**
   观测器平滑后，ACCEL 脱困/RUN/BRAKE/PASS/CAPTURE 状态机可大幅简化：只需「快速逼近（带轨迹整形）」+「到达后微修正（积分/踢动）」两态。

> 结论：**不需要**重上 LQR/滑模等高级算法也能达标；优先做「观测器 + 降带宽 PD + 轨迹整形 + 摩擦补偿」这一组合，风险最低、调试最快。若有余力且能加装角度传感器，再考虑串级内环。

## ② 数学模型

### 2.1 非线性模型（Euler-Lagrange）

状态 x = [r, ṙ, θ, θ̇]ᵀ（r 为球距摆杆中心位置，θ 为摆杆相对水平倾角，输入 τ 为电机力矩）：

```
ṙ    = v
v̇    = [M R² / (J_b + M R²)] · (r·θ̇² − g·sinθ)
θ̇   = ω
ω̇   = [τ − M·(2 r v ω + g·r·cosθ)] / (M r² + J + J_b)
```

其中 M 小球质量、R 球半径、J_b=⅖MR²（实心球转动惯量）、J 摆杆转动惯量。输出 y = r。
模型成立条件：|r| ≤ L/2（球不脱轨）、|θ| ≤ π/2（摆杆不竖直）。

**关键点**：离心项 r·θ̇² 使系统在原点的相对阶定义不完整，静态/动态反馈线性化均不严格可行，但**局部可控**，Jacobian 线性化在平衡点附近足够用于设计。

### 2.2 线性化与双积分器近似（设计用主模型）

本系统舵机是**位置式**执行器（摆角 θ 跟随指令），故取 θ 为输入、r 为输出，线性化为：

```
r̈ ≈ −(g / (1 + J_b/(M R²))) · θ = −(5/7)g·θ      （实心球滚动不滑动）
```

Laplace 变换后：

```
X(s)/Θ(s) = −(5g/7)/s²  ≈  −7.007 / s²   [m/rad]
```

这是教科书与 Quanser/Lund 实验的核心形式——**双积分器**（double integrator）：
- 开环不稳定（两个原点极点，阶跃下球一直滚）；
- 相位恒为 −180°（双积分）→ 必须用**相位超前/微分**才能稳定；
- 只靠 P 控制必然振荡或发散，PD/超前补偿是稳定化的底线。

### 2.3 本系统参数换算（对参数整定最重要的一步）

| 量 | 值 |
|---|---|
| 摆杆半长 L/2 | 125 mm |
| 球半径 R | 5 mm（直径≈10mm） |
| 滚动系数 g/(1+⅖) | (5/7)·g = 7.007 m/s² per rad |
| **换算：1° 摆角 → 加速度** | 7.007·(π/180) ≈ **122 mm/s²** |
| 满量程摆角 ±10° | ±1220 mm/s² 最大加速度 |
| 满量程摆角 ±20° | ±2440 mm/s² |

即 **a_θ ≈ 122 mm/s²/deg**，这是把位置环增益换算成闭环频率的唯一桥梁。

### 2.4 非最小相位（NMP）讨论——本系统实际影响有限

- 从**舵机指令/摆角 θ → 球位置 r**：纯双积分，**无 RHP 零点，是最小相位**。教科书常说球杆系统"NMP"主要指**从电机力矩/电压到球位置**的完整模型：因执行器（梁/电机）与传感器（球）非共位，梁的转动惯量与球的滚动耦合会产生 RHP 零点（Sobhani 1992 明确：MP/NMP 取决于球半径与建模细节）。
- 本系统舵机是位置式、梁角"给定"，等于把 NMP 环节"切掉"，故设计时不必为 RHP 零点头痛。
- 仍需注意：NMP 的物理含义——"为让球往一个方向走，梁必须先向反方向动"；若将来直接用力矩电机驱动摆杆，务必理解初始反向响应，控制器不宜对初始瞬态过度反应。

### 2.5 静摩擦/死区模型

- 沿梁方向重力分量 mg·sinθ，静摩擦上限 μ_s·mg·cosθ。
- 起滚条件：tanθ > μ_s。本系统实测 trim 偏差 1.2° 即产生 ±5mm 误差，说明**等效死区 ≈1.2° 摆角**。
- 由 Kp=0.24°/mm，死区换算成位置误差 ≈ 1.2°/0.24 ≈ **5mm**——正好卡在 1cm 指标内但余量极小，是痛点④的来源。
- 控制含义：**误差 < ~5mm 时球被静摩擦"钉住"，位置环的 P 输出（<1.2°）不足以让它动**，必须靠积分累积或踢动脉冲越过死区。

## ③ 各算法方案详述

### 方案 A：串级控制（位置外环 + 角度内环）

**结构**：外环位置控制器输出"期望摆角 θ_ref"，内环让实际摆角快速跟随 θ_ref。

**适用条件**：有摆杆/舵机角度反馈（电位计、编码器、陀螺仪）。

**关键规则——内环必须比外环快**：
- 经验规则：内环带宽为外环的 **3~10 倍**（保守整定 3~5×，激进整定需 5~10×；Skogestad 建议内环响应时间 < 外环 1/5）。
- 原因：① 内环慢则两环动态耦合、相互作用导致失稳；② 内环要先把扰动（齿轮回差、梁惯性、舵机抖动）就地抑制，不让其传到外环；③ 内环快时对外环近似增益 1（纯延迟），外环设计大幅简化。
- 实例（Lund 课件）：内环角度对象 G=4.5/s，P 增益 K₂=2.2 → 内环闭环时间常数 T₂≈0.1s、穿越频率≈10rad/s；外环看到的过程≈ (1/(1+0.1s))·(10/s²)，外环 PID 调出 ωc≈2rad/s、相位裕度≈38°。
- 实例（Quanser/UCF 工作簿）：内环伺服 PV 增益取"快得可视为理想跟踪"；外环 PD 用二阶匹配公式 Kc=2ζωn/K_bb、z=ωn²/(K_bb·Kc)，并加高通近似微分器。

**优缺点**：
- 优点：扰动抑制强、非线性弱化、外环可调更慢更稳、物理直观。
- 缺点：需额外传感器与 I/O；多一环多一组参数。

**对本系统适用性**：**好消息是舵机本身就是一个内部位置闭环**（电位计反馈），相当于"内环已存在、带宽约 5~10Hz"。因此本系统**事实上已是级联**——无需自己加内环；缺的只是对实际摆角的测量（用于校正 trim/回差）。若想进一步，可在舵机臂上加电位计/编码器或 MPU6050 测梁角，但**优先级低于观测器**。

### 方案 B：无角度反馈时的替代方案（本系统主线）

**适用条件**：只有位置反馈、执行器为位置式舵机、无内环传感器。这是本系统的现状。

1. **状态观测器（强烈推荐）**
   - 在 5ms 控制周期上用双积分模型做预测，收到 16Hz 位置帧时做校正：
     - 预测：`p̂⁺ = p̂ + v̂·Tm`，`v̂⁺ = v̂ + a_θ·θ_cmd·Tm`
     - 校正：`p̂ = p̂ + Lp·(z_k − p̂⁻)`，`v̂ = v̂ + Lv·(z_k − p̂⁻)`（z_k 为第 k 帧视觉测量，Lp/Lv 为观测器增益）
   - 增益选取：位置噪声 ±1mm → Lp 小（如 0.3~0.6），Lv 更小（如 0.05~0.15），让观测器对噪声不敏感而对模型预测信任。可先用 Kalman 调 q/r 比例。
   - **延迟补偿**：视觉测量实际滞后约 85ms。简单做法：收到帧后用"时间戳"，把测量当 85ms 前的量做"延迟更新"（backward-in-time observer），再前推到现在；工程简化版：把测量当作当前量但把闭环带宽压到 1~1.5rad/s（85ms×1.5≈8° 相位滞后，可接受）。文献（UW、NUST 等）证明多速率+延迟补偿能把跟踪误差降 90% 以上。
   - **参考实现**：捷克 CVUT 硕士论文与本系统几乎同构——相机 Tc=30ms、控制 Tm=5ms，速度用相邻帧差分 + 帧间线性插值 `d_i = d_c + i·v·T_m`，并用滑动平均平滑；效果稳定。

2. **位置微分/速度估计**
   - 直接差分噪声太大（±1~2px→速度噪声很大），必须经观测器或低通（一阶惯性 1/(Ts+1)，ω_f≈3~6rad/s）平滑。观测器是更好的选择。

3. **设定点整形（set-point shaping）**
   - 不要对阶跃目标直接反应，给参考轨迹 r(t)（见方案 D），大幅减少过冲。
   - 对 ±5cm 大目标特别有效。

4. **增益调度（gain scheduling）**
   - 大误差阶段用强增益快速逼近，小误差阶段降增益防振荡 + 启动积分/踢动。当前状态机其实是"增益调度"的雏形，但切换条件若基于"观测器速度"而非原始位置差分会更平滑。

### 方案 C：静摩擦 / 粘滑 / 死区补偿

**背景**：PID 积分在克服静摩擦时存在"积分饱和—耗尽—反向"的缓慢循环，造成极限环与长驻留时间；本系统纯 PD 无积分则完全无法克服死区，只能靠 ACCEL 反复强推。

补偿手段（由简到繁）：

1. **积分 + 抗饱和（anti-windup）——首选**
   - 加小积分项 Ki，配合 **clamping/条件积分**：当 `|u|` 饱和或误差大且指令饱和时停止积分；积分输出限幅 ±0.5°~±1°。
   - Ki 取 ωc·Kp 的 1%~5% 即可，避免引入新振荡。
   - 作用：缓慢累积越过 ~1.2° 死区，最终把稳态误差拉到观测器噪声级。

2. **死区处理 / 踢动（kick / impulsive）**
   - 当 `|r̂−r_ref| > ε`（如 3~8mm）且 `|v̂| < v_th` 且未在冷却期时，输出一个固定幅度踢动 θ_kick = ±(死区角+裕量，如 ±1.5~2°)，持续 2~5 个控制周期。
   - 相当于把现有 ACCEL 脱困"制度化"为频率受限的脉冲，避免反复振铃。
   - 注意：踢动幅度高于静摩擦但别过大，防止一踢就过头；冷却期避免连续踢。

3. **抖振（dither）**
   - 在目标附近叠加小幅高频正弦（如 ±0.3~0.5°、2~5Hz）让球保持微动不"咬死"。
   - 缺点：激励未建模高频、且会被摄像头噪声淹没、增加能耗。本系统**低优先级**，先试积分/kick。

4. **摩擦力前馈补偿**
   - 用 Stribeck/Coulomb 模型在控制器输出上叠加 `f(v̂)`，需先辨识摩擦参数。对滚动摩擦+静摩擦混合的场景，模型漂移大，**性价比低**，不推荐。

5. **Trim 自动校准（针对痛点④，强烈推荐）**
   - 上电/开局时把球放到摆杆中心（或用已知位置），PID 稳态后记录"恰好水平"的舵机指令作为 trim 偏置，写入 Flash。
   - 或运行中统计：`θ_cmd 稳态均值` 作为 trim。已有"标定持久化到 Flash"的基础（git 历史 ad42a2c），直接复用。
   - 1.2° trim 偏差 ≈5mm 误差，校准后该项基本消除。

6. **限制环抑制（若出现极限环）**
   - 死区/回差导致的极限环可用描述函数法分析；抑制手段：降增益、加积分限幅、加踢动冷却、机械消隙（垫片）。本系统先保证控制器参数不过激。

### 方案 D：快速定点 ≤5s 且误差 ≤1cm——时间最优与轨迹整形

**核心认知**：±5cm 折返 100mm，以 θ_max=10°（加速度 1220mm/s²）计算，双积分器时间最优 bang-bang 用时 **T=2·√(Δx/a_max)=2·√(100/1220)=0.57s**；即"跑"本身远在 5s 内。**真正的挑战是"停"（过冲、摩擦死区、收敛慢）**。

1. **时间最优 bang-bang**
   - 理论上最优：满加速→满减速（双积分器的 Pontryagin 解）。
   - 现实问题：参数敏感、开关噪声、末端残振、易过冲，纯 bang-bang 在摩擦+延迟下会"冲过头再回来"，比不优化更差（文献一致结论）。
   - **本系统不直接用纯 bang-bang**，只借鉴其"大误差满偏"思想。

2. **梯形/三角速度规划（推荐）**
   - 生成参考轨迹 r(t)、ṙ(t)、r̈(t)：限加速度 a_max、限速度 v_max，点对点梯形速度剖面（短距离即三角）。
   - 控制器跟踪：`θ_cmd = Kp·(r−p̂) + Kd·(ṙ−v̂) + θ_ff`，其中前馈 `θ_ff = r̈/a_θ`。
   - 参数建议：`a_max=300~600mm/s²`（≈2.5~5° 稳态倾角），`v_max=120~200mm/s`。
   - 预算核算（a_max=400，v_max=160，Δx=100mm）：加加速 0.4s + 匀速 0.625s + 减速 0.4s ≈ **1.4s** 走完，余 ~3.5s 驻留收敛。留足裕量。
   - 优点：速度/加速度全程有界、无过冲、末端自然减速，与 16Hz 反馈兼容。

3. **设定点整形 / 输入整形（input shaping / Posicast）**
   - 对欠阻尼二阶系统，用 ZV/ZVD 整形把阶跃拆成两个延迟脉冲，抵消振荡、零过冲。对"位置环 PD 形成的闭环二阶动态"有效。
   - 本系统闭环目标 ζ≈0.8 欠冲较小，输入整形收益有限，可作为备选；梯形规划更直接。

4. **过冲抑制（相位裕度、预测制动）**
   - 保证闭环相位裕度 ≥40°（本系统降带宽 + 观测器后自然满足）。
   - "预测制动"：轨迹发生器已经内建减速段，比"到目标才刹车"的纯反馈更不易过冲——这是比当前 BRAKE 状态机更平滑的方案。

### 方案 E：状态反馈控制（LQR / 极点配置）

**结构**：对线性化 4 阶模型（或双积分 2 阶模型）设计 `u = −K·x̂`，x̂ 来自观测器；跟踪时加前馈/积分（LQI）消除稳态误差。

- **LQR**：最小化 J=∫(xᵀQx + uᵀRu)dt，增益 K=R⁻¹BᵀP（Riccati 解）。Q/R 直接对应"快速性 vs 摆角幅度/能耗"。文献比较结论：球杆/球板系统上 LQR 通常优于极点配置（IEEE ICICCS 2021）。
- **极点配置**：可显式指定闭环极点（如 CTMS 例题：-2±2i、-20、-80，K=[1828.6, 1028.6, 2008, 104]），但可能要求过大的控制力。
- **实现要点**：
  - 必须**离散化**在 5ms 周期实现（`c2d` + 离散 Riccati）；
  - 需要**观测器提供全部状态**（尤其速度），与低帧率视觉配合的观测器是成败关键；
  - 加**积分/前馈**处理 trim 与稳态误差；
  - 对 Q/R 从"ωc≈1~1.5rad/s、ζ≈0.8"反向推导初值，而不是拍脑袋。
- **对本系统**：LQR 可做但**非必需**。其收益主要体现在"多状态协调"（若把梁角动态也算进去），而本系统舵机已位置化，双积分 + PD(等价于极点在 1~2rad/s 的全状态反馈) 已足够。若想升级，建议从 PD 参数对应的高斯极点（如 s=-1.2±1.2i）出发做 LQI。

### 方案 F：控制频率与传感器帧率的关系

**结论**：**16Hz 视觉反馈本身不是硬瓶颈，85ms 延迟 + 无观测器才是**。

- 球杆系统位置环带宽需求很低：球运动能量集中在 0~2Hz（Barranco 论文实测），闭环带宽取 0.2~0.5Hz 即满足 5s 指标。
- 反馈速率/带宽经验比：反馈率 ≈ 10~30× 闭环带宽即可，16Hz / 0.3Hz ≈ 50×，**充足**。
- 真正约束：**延迟**。85ms 延迟在 ωc=2rad/s 处引入相位滞后 ≈10°，在 ωc=5.4rad/s 处 ≈26°——这才是当前过冲的根因。
- 缓解三件套：
  1. **降闭环带宽**到 1~1.5rad/s；
  2. **观测器帧间预测**（5ms 更新，把"每 85ms 一跳"变成连续状态）；
  3. **延迟补偿**（时间戳/延迟更新，或修改版 Smith 预测器——但文献显示视觉延迟场景 Kalman 预测通常优于 Smith）。
- 控制周期 5ms vs 位置 85ms 属**多速率控制**；观测器天然处理多速率（快速预测 + 慢速校正）。若实在要省算力，CVUT 做法（相邻帧差分速度 + 线性插值 + 滑动平均）也可用，但鲁棒性不如观测器。

## ④ 针对本系统的推荐方案与理由（组合拳）

### 推荐实现层次（按投入/收益排序）

| 层 | 做法 | 解决痛点 | 预计收益 |
|---|---|---|---|
| L0（必做） | **状态观测器**（200Hz 预测 + 16Hz 校正，双积分模型） | ②③④ | 位置/速度连续化、延迟补偿、消除反馈跳变 |
| L1（必做） | **降带宽位置环**（ωc≈1~1.5rad/s、ζ≈0.7~0.9）+ **小积分带抗饱和** | ②③ | 消除过冲与 ACC/PASS 极限环、收敛变快 |
| L2（必做） | **梯形速度规划参考轨迹 + 前馈** | ②③ | ≤5s 快速定点、无过冲、末端自然减速 |
| L3（强烈建议） | **摩擦补偿**：定点 kick + trim 上电自校准（复用 Flash 标定） | ①④ | 越过 1.2° 死区、消除 ±5mm 驻留误差 |
| L4（可选） | 简化状态机为「逼近 + 驻留」两态；增益调度 | ③ | 逻辑更清晰 |
| L5（可选，有传感器则做） | 加摆杆角度测量做真串级/trim 实时校正 | ④ | 进一步压误差 |

### 参数初值建议（供现场整定起点）

系统增益 a_θ ≈ 122 mm/s²/deg。目标 ωc=1.2rad/s、ζ=0.8：

```
Kp = ωc²/a_θ   = 1.44/122   ≈ 0.012 °/mm      （现 0.24 的 1/20！）
Kd = 2ζωc/a_θ  = 1.92/122   ≈ 0.016 °/(mm/s)  （与现 0.040 同量级，略降）
Ki ≈ 0.02·Kp·ωc ≈ 0.0003 °/(mm·s)，限幅 ±0.8°
观测器：Lp≈0.4，Lv≈0.08（帧率等效），或 Kalman q/r 按位置噪声±1mm、过程噪声按 a_θ·θ 模型误差调
轨迹：a_max=400mm/s²（≈3.3°）、v_max=160mm/s → 100mm 约 1.4s
踢动：|e|>5mm 且 |v̂|<10mm/s 且冷却 300ms 时，θ_kick=±1.6° 持续 20ms
```

> 注意：以上为**理论起点**，因实际存在回差、舵机动态、滚动摩擦系数未知，需在整定中缩放。核心原则：**带宽先压下来，验证不再振荡，再逐步放开**；Kp 从 0.005 起步向 0.02 爬，Kd 同步配阻尼。

### 关键理由总结

1. **观测器是把 16Hz+85ms 延迟"变废为宝"的唯一低成本手段**，直接让闭环可以调得比当前更稳（而不必像现在靠激进 PD 硬顶）。
2. **当前过冲的数学根因是 Kp 相对延迟过大**（ωn=5.4rad/s × 85ms ≈ 26° 相位滞后 + 双积分 −180° → 相位裕度极小）。降带宽不是"变慢"，而是"从振荡中救回来"，配上轨迹整形后总时间反而更短。
3. **静摩擦死区 ≈5mm 是 1cm 指标的最大威胁**，必须用积分/kick/trim 三件套消除，纯靠位置 PD 无法根治。
4. **5s 时间预算非常充裕**（理论跑程 <1.5s），时间约束几乎不构成压力，压力全在"停得准"。
