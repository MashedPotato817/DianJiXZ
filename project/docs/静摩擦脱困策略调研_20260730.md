# 球杆平衡系统静摩擦脱困策略调研

> 最后更新：2026-07-31 10:55
>
> 用途：为 K230 + MSPM0 上层小球闭环的下一步控制决策提供依据；本文**不修改现有控制代码，也不代表已经完成硬件验证**。

## 1. 问题定义与已知边界

当前系统在小球位于视野内、位置误差仍明显（例如 `+40 mm`）时，可能长时间停在原处。此时舵机已按 PD 输出偏转，但经齿轮—摇杆后的实际倾角不足以克服静摩擦、传动间隙或负载阻力；小球一旦开始滚动，所需维持力通常又会小于起动力。这是典型的 *stiction*（静摩擦卡滞）而不是把目标设为 `+40 mm`。

本工程已确认的条件如下：

| 项目 | 当前事实 | 对策略的约束 |
|---|---|---|
| 舵机 | 机械允许 `5–175°`；`90°` 仅为上电初值 | 不假定存在固定平衡 PWM；所有命令仍必须限幅。 |
| 正常控制 | PD 快速纠偏相对动态 `trim` 限幅 `±20°` | `trim` 仅补偿慢变偏置，起动力不能被学习进 `trim`。 |
| 机械传动 | 舵机 `180°` 约对应摇杆 `11°` | `12°` 舵机偏转仅约 `0.73°` 摇杆偏转；“看起来很大”的舵机角度未必足以起球。 |
| 视觉与链路 | K230 临时位置、实测约 `16 Hz`，非正式五点标定 | 脱困判断只使用**新鲜有效帧**；短脉冲必须覆盖至少 2 个视觉帧才可判定效果。 |
| 已验证方向 | `x>0` 时提高 PWM，球向左、`x` 减小 | 起动力方向与现有 PD 保持一致，绝不可通过猜测反向。 |
| 安全范围 | 机械允许 `5–175°` | 动态 `trim` 进一步限在 `15–165°`，给快速纠偏保留余量。 |

本调研开始前，代码的 `breakaway_active` 是“停滞满 500 ms 后，将 PD 输出抬至同方向至少 `12°`”。它没有独立的脉冲时长、冷却时间或缓释阶段。因此在 `+40 mm` 处，普通 PD 约为 `0.24×40=9.6°`，只会被抬到 `12°`；若 `12°` 未达到起动力，球仍会停住；若后续把固定最小值调得过大，又可能一直维持大倾角并过冲。

## 2. 权威资料与可迁移结论

### 2.1 资料来源

1. Rockwell Automation，《[Motion System Tuning Application Techniques](https://literature.rockwellautomation.com/idc/groups/literature/documents/at/motion-at005_-en-p.pdf)》，2024，章节 *Static Friction*。工业运动控制资料明确指出：显著位置误差下负载仍可能因 sticktion 不动；积分可积累足够驱动力但响应未必合适。其静摩擦补偿做法是在输出同向叠加固定补偿，并用 *Friction Compensation Window* 按误差比例缩放；窗口内禁用积分以减轻 hunting。补偿过大将造成 dither（目标附近快速往复）。
2. Rockwell Automation，[Axis Servo: Friction/Deadband Compensation](https://www.rockwellautomation.com/en-pr/docs/studio-5000-logix-designer/37-00/contents-ditamap/studio-5000-logix-designer/axis-properties-for-ethernet-motion-system/configure-the-axis-properties/offset-tab-overview--axis_servo-.html)。官方参数说明再次强调：补偿用于“有非零误差但轴不动”；其值过大将引起 dither，并配合补偿窗口使用。
3. Beckhoff，[Friction compensation](https://infosys.beckhoff.com/content/1033/tf5200_axis_compensation/1085841163.html)。其 CNC 补偿本质是随速度的附加电流前馈，用于降低位置滞后及反向间隙。可迁移的结论是“摩擦补偿是已知扰动的附加前馈，需先获得本机构特性”；不可直接搬用其电流表或速度表参数。
4. Armstrong-Hélouvry、Dupont、Canudas de Wit，[A Survey of Models, Analysis Tools and Compensation Methods for the Control of Machines with Friction](https://doi.org/10.1016/0005-1098(94)90209-7)，*Automatica*, 1994。同行评审综述指出，补偿效果高度依赖摩擦模型质量与所选分析方法；因此不能把其他伺服平台的起动力数值直接移植到本球杆机构。
5. MathWorks，[Anti-Windup Control Using PID Controller Block](https://www.mathworks.com/help/simulink/slref/anti-windup-control-using-a-pid-controller.html)。官方控制文档说明执行器饱和时，积分会继续累积并造成反向恢复迟缓；可用 clamping（条件积分）或 back-calculation（反算）处理。
6. Nakano，[A Proposal on the Dither](https://doi.org/10.11499/sicejl1962.3.262)，*Journal of the Society of Instrument and Control Engineers*, 1964。同行评审文献分析了以 dither 减弱静摩擦所引起死区/滞回的机理，并指出幅值和频率需要针对被控对象选取，而不是有通用固定值。

### 2.2 结论边界

上述工业资料多数面对有电流/速度内环的工业伺服；本工程向标准位置舵机给的是角度/PWM 命令，外环又受约 `16 Hz` 视觉采样限制。因此可迁移的是**结构性方法**（门限、限幅、窗口、迟滞、超时、anti-windup），不可迁移的是电流百分比、摩擦表、dither 频率或任意“推荐增益”。

## 3. 方案比较

| 方案 | 是什么 | 适用性与收益 | 主要风险 | 本工程结论 |
|---|---|---|---|---|
| 死区 + 最小有效控制 | 小误差不动；误差足够大时将输出至少抬到同方向最小值，可在误差窗口内平滑缩放 | 简单，适合消除小输出不足；Rockwell 的补偿窗口能降低突变 | 若长期持续叠加，容易造成偏置、抖动或过冲；阈值若小于视觉噪声会反复切换 | 保留 `1 mm` 死区；可作为起动力后的辅助，但不宜单独解决“完全卡住”。 |
| 短时起动力脉冲（kick-start / breakaway pulse） | 仅在确认“有误差且连续静止”后，同方向施加一个有时限的较大偏转，再退出 | 最符合当前“先让球动，再动态回调”的需求；不会无限维持大偏转 | 脉冲过大/过久会加速过冲；低帧率下必须按帧检测起动结果 | **已按本策略实现，待实测**：受限、一次性的状态机，不直接提高常规 `Kp`。 |
| 摩擦前馈补偿 | 在 PD 输出上叠加与运动方向、速度或已辨识摩擦有关的偏置 | 已知机械特性后可降低稳态误差 | 本系统没有摇杆角度/扭矩反馈，且摩擦受装配影响；模型错会持续施加错误偏置 | 先通过脉冲标定取得“最小可靠起动力”，后续再考虑误差窗口式前馈。 |
| 连续 dither | 在输出叠加零均值小振荡，使机构不长期停留在静摩擦区 | 在高带宽阀/驱动中常见 | 增加振动、磨损和视觉位置噪声；50 Hz 位置舵机与 16 Hz 视觉外环不适合先尝试高频 dither | **当前不推荐**；只有脉冲和窗口补偿均失败、且可测得舵机实际响应时再单独试验。 |
| 积分 I | 按长期误差累积输出，理论上可跨过起动力 | 可消除静态偏差 | K230 临时映射、丢帧/边缘恢复、输出饱和时都易 windup；会掩盖机械与视觉问题 | **当前不推荐直接加入**。若未来加入，必须先实现输出饱和、条件积分/反算、积分冻结与复位。 |

## 4. 推荐的“受限起动力 + 动态回调”状态机

该方案把“先大力启动、再动态回调”明确拆成状态，不把大偏转混入普通 PD。下列为建议设计，**参数均待实测，不是可直接写死的数值**。

```text
OFF/LOST ── 有新鲜有效帧 ──> TRACK(PD)
  ▲                               │
  └── 丢帧、无效非边缘帧、异常 ────┘

TRACK(PD) ── |e|≥E_enter 且 N 个新帧内位移≤X_still ──> STUCK_CONFIRM
STUCK_CONFIRM ── 连续 T_confirm 仍静止 ───────────────> KICK
STUCK_CONFIRM ── 已运动/误差回到退出门限 ─────────────> TRACK(PD)
KICK ── 已移动、达到 T_kick、或反向运动 ─────────────> SETTLE
SETTLE ── T_cooldown 后 ─────────────────────────────> TRACK(PD)
```

### 各状态的动作

1. **TRACK(PD)**：仅在 K230 收到新时间戳的有效帧时计算 PD；保留现有方向、死区与常规 `±20°` 限幅。
2. **STUCK_CONFIRM**：要求 `|e|` 大于进入门限、位置在多个新帧内的累计变化小于经视觉噪声确认的阈值、且无丢帧。使用进入/退出两套门限（迟滞）防止 `OK/HD` 附近反复进出。
3. **KICK**：输出 `sign(e) × max(|u_PD|, U_kick)`，并限制为 `T_kick`；对本工程的正误差，命令应为“提高 PWM”，与已确认方向一致。起动检测到 `|Δx|` 超过阈值、运动方向正确、或时间达到上限，立刻退出；在单次脉冲期间不叠加 I。
4. **SETTLE**：立即回到受限 PD（必要时在很短的缓释时间内将输出从 `U_kick` 下降到 `u_PD`），并在 `T_cooldown` 内禁止再次 kick，避免每帧连续猛推。若球继续向目标方向运动，PD 的 D 项负责提前收力；若已越过目标，常规 PD 反向拉回。
5. **LOST/EDGE**：继续使用现有丢帧回中与左右边缘恢复逻辑。任何视觉失效都取消 `KICK` 与确认计时，避免对未知位置继续施加起动力。

### 建议首先标定的量

| 参数 | 定义 | 为什么不能直接给最终值 |
|---|---|---|
| `U_kick` | 触发脱困时的舵机相对中位偏转 | 由摩擦、齿隙、球质量、杆角和供电决定；`12°` 在本机构已显示可能不足。 |
| `T_kick` | 单次起动力保持时间 | 受舵机实际响应和约 `16 Hz` 视觉采样影响；应以 2、3、4 个新帧为单位测试，约 `125/188/250 ms`。 |
| `E_enter/E_exit` | 进入/退出脱困的误差门限 | 需高于临时像素到毫米映射的抖动，并保留迟滞。 |
| `X_still`、`T_confirm` | 判定“确实没动”的位移和时长 | 现有 `2 mm / 500 ms` 只能作为初值；必须由静置日志的分位数决定，而非凭感觉。 |
| `T_cooldown` | kick 后禁止重触发的时间 | 与球从静止到可观测运动的延迟有关，过短会连击，过长会失去恢复能力。 |

## 5. 安全边界与不推荐做法

### 必须保持的安全边界

- `KICK` 仅对**新鲜、有效、非边缘恢复**的 K230 帧触发；链路超时或 `valid=0` 时立刻取消。
- 首轮起动力扫描不突破普通控制 `±20°`；`90±80°` 仅保留给已有的左右边缘恢复，不用于解决视野内卡滞。
- 每次只允许一个有上限的 kick，必须设置 `T_cooldown` 和每秒最大次数；出现反向位移、越过中心过多或观测异常时取消。
- 记录每次状态转换：帧序号、`x_mm`、误差、PD 输出、`U_kick`、持续时间、起动后位移与最终状态。仅记录必要事件，不恢复终端刷屏。
- 在正式五点标定前，将结果描述为“改善可运动性”，不把 `x_mm` 当作精确物理位置结论。

### 当前不推荐

- **不直接把常规 `Kp` 大幅提高**：它会同时放大运动过程的控制，不只影响卡滞点，易导致两侧摆动。
- **不把 `12°` 简单改成持续更大最小值**：这不是“先启动后回调”，而是永久偏置，最容易引发 dither/过冲。
- **不先加积分**：在 16 Hz 视觉、临时映射、链路失效和输出限幅并存时，未做 anti-windup 的 I 项风险高。
- **不先加连续 dither**：位置舵机与低频视觉外环无法确认高频小振动的真实机械效果，且会增加摆杆/小球振动与识别噪声。
- **不使用其他设备的电流、百分比或频率参数**：本系统没有等价的电流扭矩接口，传动比和实际摩擦不同。

## 6. 建议实测步骤（先验证再改控制）

1. **保持静止基线**：舵机 `90°`，分别将球放在 `+30 mm`、`+40 mm`、`-30 mm` 等可稳定复现位置；每点记录至少 5 次静置段，统计 K230 位置抖动的中位数与高分位范围，作为 `X_still` 下限依据。
2. **方向复核**：只做一个受限、短时的开环偏转，确认正偏转仍使 `x` 减小、负偏转使 `x` 增大。方向不一致时停止，不进入闭环调参。
3. **最小可靠起动力扫描**：在普通 `±20°` 内，以固定短时长逐档测试 `U_kick`；每档从多次重复的“是否在 2–3 个新帧内产生超过噪声的正确位移”判断，采用成功率和中位位移，不取单次平均。选取**可靠起动的最小档**，而非最大档。
4. **脉冲时长扫描**：固定已选 `U_kick`，以 2、3、4 个新帧测试 `T_kick`，记录是否起动、最大偏移、首次反向时间及是否越过中心。选择最短可靠时长。
5. **闭环状态机联调**：先只开启单次 `KICK→SETTLE→PD`；验证每次卡滞只触发一次且会退出。然后再调 `T_confirm` 与 `T_cooldown`，最后才微调 `Kp/Kd`。
6. **对比验收**：使用同一初始位置、同一球、同一供电条件，比较改动前后“起动成功率、回到中心时间、最大超调、每分钟 kick 次数、视觉丢失次数”。若无法测得改善，回退策略而非继续叠加功能。

## 7. 推荐决策

用户提出的“先用较大力让球开始运动，然后动态回调”是合理方向，应实现为**有确认条件、固定最短持续时间、立即退出且带冷却的 kick 脉冲**，而不是永久增大当前 `12°` 最小输出。它是当前最小、可观察、可回退的改动。

### 7.1 实现状态（2026-07-31 10:55）

当前 `project/mspm0/Control/ball_control.*` 已改为由运动证据驱动的 `ACCEL→RUN→BRAKE→CAPTURE` 状态机：

- 目标外且未向中心运动时立即进入 ACCEL，连续施加 `20°→24°→28°`，档位之间不回中。
- 连续两帧确认朝中心速度达到 `12 mm/s` 后进入 RUN，保持至少 `12°` 驱动力。
- 用 `v²/(2a)` 估算制动距离，进入 BRK 后至少施加 `6°` 反向制动。
- 只有 `|error|≤2 mm` 且 `|velocity|≤8 mm/s` 才进入 CAP；非目标位置静止不会被接受为稳定状态。
- 90°只作为上电初值。中心附近低速时以受限条件积分慢速学习 `trim`，范围 `15~165°`；ACC、丢帧、边缘和故障阶段冻结。
- 普通丢帧在总有效样本年龄 `180 ms` 内保持上一输出，之后回到动态 `trim`；机械绝对限位为 `5~175°`。
