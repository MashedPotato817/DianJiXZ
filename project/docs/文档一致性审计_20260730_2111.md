## 时间戳规范

从本审计之后，所有**自维护的工程 Markdown 文档**采用以下格式，精确到分钟：

```markdown
> 最后更新：YYYY-MM-DD HH:MM
```

规则：

1. 放在标题后的第一行；长文档在末尾重复一行，便于查看截取内容时判断时效。
2. 仅在内容实际变更时更新；禁止为“看起来新”而批量刷新历史文档的时间。
3. 历史/参考文档增加“范围”或“最后核对”说明，不把历史硬件定义伪装成当前 H 题配置。
4. 测试记录同时写入分钟时间、提交号、固件/参数版本、硬件条件、原始日志路径和结论等级。
