# UART0 AI 调试遥测说明

> 最后更新：2026-07-30 23:37

## 目的

MSPM0 将 K230 视觉帧、同一时间窗内的双编码器增量、舵机命令和串口链路状态汇总到一条时间轴。串口助手保存原始 TXT 后，可直接交给 AI 判断问题更接近视觉、通信、控制输出还是机构没有响应。

## 接线与串口参数

```text
MSPM0 PA10 / UART0_TX -> USB-TTL RX
MSPM0 PA11 / UART0_RX <- USB-TTL TX（当前只采集日志时可不接）
MSPM0 GND             -> USB-TTL GND
```

使用 3.3 V TTL，配置为 115200、8 数据位、无校验、1 停止位。UART0 内部回环必须关闭。

K230 链路仍使用 UART1：

```text
K230 IO40 / UART1_TX -> MSPM0 PB7 / UART1_RX
K230 IO41 / UART1_RX <- MSPM0 PB6 / UART1_TX
```

## K230 到 MSPM0 的帧

```text
$K230,BALL,<x_mm>,<valid>,<seq>,<edge>,<k_ms>,<center_px>,<fps_x10>#
```

- `k_ms`：K230 的相对毫秒时间。
- `center_px`：原始球心横坐标；没有检测到完整球时为 `-1`。
- `fps_x10`：检测 FPS 乘 10。
- MSPM0 仍兼容没有扩展字段的旧 BALL 帧。

## MSPM0 到电脑的帧

程序上电立即输出字段表，并每 5 秒重发一次：

```text
#TELEM_V1,t_ms,dt_ms,k_ms,rx_ms,rx_age_ms,seq,x10,valid,edge,px,fps10,encA,encB,servo_us,out10,ctrl,parse_err,seq_gap,rx_overrun,timeout#
```

之后每 50 ms 输出：

```text
$T,50,50,13820,45,5,1,42,1,0,161,405,3,-2,1653,96,1,0,0,0,0#
```

| 字段 | 含义 |
| --- | --- |
| `t_ms` | MSPM0 上电后的相对毫秒时间 |
| `dt_ms` | 本行编码器累计窗口的实际长度，正常约 50 ms |
| `k_ms` | K230 生成该视觉帧时的相对毫秒时间 |
| `rx_ms` | MSPM0 解析该视觉帧的本地时刻 |
| `rx_age_ms` | 输出本行时，最近视觉帧已经过去的毫秒数 |
| `seq` | K230 视觉帧序号 |
| `x10` | 小球位置毫米值乘 10，例如 `42` 表示 `+4.2 mm` |
| `valid` | `1` 为可靠检测，`0` 为保持/丢失或链路失效 |
| `edge` | `-1` 左边缘、`+1` 右边缘、`0` 非边缘 |
| `px` | K230 原始球心横坐标；`-1` 表示无完整球心 |
| `fps10` | K230 FPS 乘 10 |
| `encA`、`encB` | `dt_ms` 窗口内两路车轮编码器累计增量 |
| `servo_us` | 实际写入舵机 PWM 的高电平脉宽，单位 μs |
| `out10` | 控制器相对中位输出角度乘 10 |
| `ctrl` | 控制状态编码，见下表 |
| `parse_err` | MSPM0 累计 K230 帧解析错误数 |
| `seq_gap` | 根据 K230 序号发现的累计缺帧数 |
| `rx_overrun` | MSPM0 UART1 接收环形缓冲累计溢出数 |
| `timeout` | `1` 表示超过 100 ms 未收到有效 K230 帧 |

控制状态：

| `ctrl` | 状态 |
| ---: | --- |
| 0 | `OFF`，闭环关闭 |
| 1 | `PD`，正常位置控制 |
| 2 | `STK`，静摩擦启动 |
| 3 | `DRV`，启动后的持续驱动 |
| 4 | `EDGE`，视野边缘恢复 |
| 5 | `FLT`，连续脱困失败 |
| 6 | `COOL`，脱困重试间隔 |

## 采集与交给 AI

1. 先连接串口助手，再复位 MSPM0，确认能看到 `#TELEM_V1`。
2. 开启“保存接收数据到文件”，关闭十六进制显示，不要删除 `$T`、`#` 或字段表。
3. 至少记录一次小球静止、开始运动、越过中心和重新稳定的完整过程。
4. 把 TXT 原样交给 AI，并说明实验中球的初始位置、是否触碰机构、是否手动干预。

软件验证状态：SysConfig 已按 PA10/PA11、115200 8N1、关闭内部回环重新生成；Keil 构建为 `0 Error(s), 0 Warning(s)`。UART0 物理输出和日志内容仍待实机验证。
