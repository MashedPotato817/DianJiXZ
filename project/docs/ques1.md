# 新巡线核心问题：中心软化没有覆盖相邻单灯

## 当前结论

当前三次软化只能减小部分中心双灯组合的转向，尚未覆盖最容易造成直线摆动的
“中心单灯切换到相邻单灯”。因此这版可以用于验证，但不能预期仅靠该改动消除
直线左右摆动。

## 静态证据

灰度传感器总跨距为 `85 mm`，相邻通道间距为：

```text
85 / 7 = 12.143 mm
```

通道 3、4 的单灯或双灯组合由 `GRAY_CENTER_SENSOR_MASK = 0x18` 强制设为
中心直走。距离中心最近的非中心单灯是通道 2、5，其位置为：

```text
±1.5 × 12.143 = ±18.214 mm
```

但当前软化范围为：

```c
#define GRAY_SOFTEN_MM 18.0f
```

且代码只在 `abs(position) < 18.0 mm` 时执行三次软化。由于
`18.214 mm > 18.0 mm`，通道 2、5 单灯不会被软化。

以当前 `105 mm/s` 基础速度计算，典型位型的目标变化为：

| 灰度位型 | 控制使用的偏差 | `Move_Z` | 左/右目标速度 |
|---|---:|---:|---:|
| 通道 3 单灯 | `0 mm` | `0` | `0.105 / 0.105 m/s` |
| 通道 2+3 双灯 | `-5.526 mm` | `+0.084 rad/s` | `0.098 / 0.112 m/s` |
| 通道 2 单灯 | `-18.214 mm` | `+0.272 rad/s` | `0.081 / 0.129 m/s` |

右侧位型与上述结果镜像。

因此，如果直线行驶时灰度位型在通道 3 与通道 2 单灯之间切换，转向指令仍会在
`0` 和约 `0.272 rad/s` 之间跳变。三次函数本身虽然连续，但输入仍是离散的
二值灰度组合，当前阈值没有覆盖这个关键跳变。

## JY62 车体巡线数据

`project/docs/jy62/jy62_20260730_111335.csv` 是小车实际巡线时固定在车体上的
JY62 记录，与管子或滚球控制无关。采集工具 README 中的管子示例只是通用应用
说明，不能作为本次数据的实验背景。

该文件共有 3063 行，记录约 140.27 秒。主要动态集中在车体偏航轴：

| 指标 | 结果 |
|---|---:|
| `wz` 范围 | `-70.07 ~ +108.64 deg/s` |
| 展开后的累计 yaw 变化 | `1414.45 deg` |
| `wz` 积分角度 | `1411.31 deg` |
| 两种累计角度差值 | `3.14 deg` |
| yaw 变化率与 `wz` 的相关系数 | `0.9926` |

这说明清洗后 JY62 的偏航角和 Z 轴角速度具有较好的一致性，可以用来评价车体
左右摆动的幅度、频率和修改前后变化。Roll/Pitch 基本稳定，也符合传感器平放在
车体上、主要观测巡线横摆的用途。

但原始时间戳包含约 250 条重复记录、33 次倒退以及最长约 1.24 秒的数据缺口。
分析前必须按 `ts_ms` 排序、删除重复时间戳并标记长缺口。清洗后的有效采样率约
20 Hz，不能直接按采集工具 README 中的理想帧率做频谱计算。

该 CSV 没有同步记录灰度掩码、`P/Z`、左右轮速和 PWM，因此它只能证明车体的
实际横摆结果，不能单独证明是哪一种灰度位型触发了摆动，也不能单独证明
`GRAY_SOFTEN_MM` 就是根因。要建立因果关系，仍需将 JY62 时间戳与下述控制量
同步采集。

## 最小验证

暂不增加 PD、复杂滤波或赛道状态机。保持当前代码，只在直线段同步记录：

```text
灰度掩码 G
软化后的线路位置 P
角速度 Z
左右目标速度
左右实际速度
左右 PWM
```

重点判断：

1. 如果摆动时主要出现 `0x08 ↔ 0x04` 或 `0x10 ↔ 0x20`，说明相邻单灯跳变
   就是当前软化遗漏的核心问题。
2. 如果 `G/P/Z` 已稳定而车体仍摆动或顿挫，再检查速度环、编码器和电机执行链，
   不继续盲调巡线权重。
3. 如果修改软化范围，必须重新核算上述三组位型的 `P/Z/左右目标速度`，并同时
   验证操场形弯道响应，避免只改善直线却削弱转弯。

## 通过条件

- 直线段不再持续出现左右交替纠偏；
- 左右目标速度连续，没有周期性的单轮接近零；
- 弯道仍能及时产生足够的转向量；
- 结论有同一次实车测试的 `G/P/Z`、目标/实际轮速和 PWM 记录支持。
