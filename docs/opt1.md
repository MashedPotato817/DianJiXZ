# opt1：提速巡线的抗摆与急弯/发卡方案

日期：2026-07-27  
目标工程：`firmware/WHEELTEC_C07A_CAR_SPEEDUP`  
性质：下一轮控制改动的实施与实车验证方案；本文件本身不改变控制代码。

## 1. 结论与范围

本轮解决两类问题：

1. 直线时的左右摇摆：消除灰度离散读数在速度阈值附近触发的反复降速/提速，并降低外环对单帧噪声的敏感性。
2. 直角弯与发卡弯（转向角大于 90°）：在丢线前主动进入定向的低速原地转向，而不是只依赖全白后的被动搜线。

不在本轮范围内：修改轮距、编码器换算、TB6612 方向、SysConfig、视觉/IMU，或一次性重调速度 PI 的 `Kp/Ki`。

## 2. 当前代码事实

以 `WHEELTEC_C07A_CAR_SPEEDUP/Control/control.c` 和 `control.h` 为唯一实现依据：

| 项目 | 当前值/行为 |
| --- | --- |
| 控制周期 | 5 ms（200 Hz） |
| 灰度位置 | 8 路数字量的加权质心；总跨距 85 mm，单路间距约 12.14 mm |
| 前视距离 | 134 mm（传感器至左右轮中心中点实测） |
| 普通线速度 | 90 mm/s |
| 弯道线速度 | 75 mm/s |
| 降速条件 | `abs(pos) >= 18 mm` 或 `black_count >= 4` |
| 转向 | `Move_Z = -GRAY_STEER_GAIN × Move_X × curvature`，其中增益为 1.70 |
| 常规角速度限幅 | ±0.40 rad/s |
| 全白恢复 | 停止前进，沿最近一次有效偏线方向以 ±0.50 rad/s 原地搜线 |

当前没有“直线/转弯”状态机；每个 5 ms 周期都以原始灰度帧重新选择 90 或 75 mm/s。阈值没有滞回和连续帧确认，因此在 `18 mm` 或 `4 路黑线`附近，速度与角速度会来回跳变。

速度切换会同步改变转向量：在 `18 mm` 偏差处，按当前几何与增益计算，90 mm/s 时约为 `0.301 rad/s`，75 mm/s 时约为 `0.251 rad/s`；单次切换产生约 `0.050 rad/s` 的转向阶跃。

在最大可见横向偏差约 42.5 mm 时，75 mm/s 下未限幅的转向请求约为 `0.548 rad/s`，会被压到 `0.40 rad/s`。此时车体理论最小常规转弯半径为 `0.075 / 0.40 = 187.5 mm`，不足以稳定通过部分直角和发卡弯。

## 4. 最终控制方案

### 4.1 灰度位置：保留原始值，同时加入仅供普通巡线使用的滤波值

新增：

```c
Gray_Line_Pos_Raw_mm       // 本帧质心，保留用于急弯检测和显示
Gray_Line_Pos_Filtered_mm  // 一阶低通后的位置，仅用于普通巡线
```

滤波公式：

```text
filtered = 0.35 × raw + 0.65 × filtered
```

规则：

- `raw` 仍由现有 8 路质心计算得到，不能改写传感器坐标或黑白极性。
- 普通巡线的曲率和速度判定使用 `filtered`，降低单帧数字灰度跳变带来的方向抖动。
- 急弯检测始终使用 `raw` 和最外侧传感器状态，不受滤波延迟影响。
- 首次识别到黑线、全白后重新识别黑线时，令 `filtered = raw`，避免滤波器历史值造成错误转向。

### 4.2 两档速度：加入滞回与连续帧确认

新增 `gray_curve_mode`，不再每帧直接覆盖速度档位。

| 动作 | 条件 | 连续帧数 |
| --- | --- | --- |
| 进入弯道档 | `abs(filtered) >= 18 mm` 或 `black_count >= 4` | 2 帧（10 ms） |
| 退出弯道档 | `abs(filtered) <= 12 mm` 且 `black_count <= 2` | 3 帧（15 ms） |

进入后 `Move_X = 75 mm/s`，退出后恢复 `90 mm/s`。普通巡线的转向公式、轮速逆解和 ±0.40 rad/s 常规限幅保持不变。

这样做的目的不是让车“更慢”，而是避免位置在单一阈值附近时产生 90/75 mm/s 反复跳变；进入弯道比退出更敏感，退出要求更严格。

### 4.3 急弯/发卡状态机

新增独立于速度档位的状态：

```text
FOLLOW          正常巡线，使用第 4.1 和 4.2 节逻辑
SHARP_TURN      主动急弯/发卡转向
LOST_SEARCH     全白后的兜底搜线
```

#### 进入 `SHARP_TURN`

满足以下条件连续 2 帧时进入：

```text
abs(Gray_Line_Pos_Raw_mm) >= 30 mm
且黑线命中该侧最外两路之一：左侧 channel 0/1 或右侧 channel 6/7
```

进入时锁存方向，不在转向过程中因新一帧读数改变：

```text
line 在右侧  -> 锁存当前代码约定的右转角速度符号
line 在左侧  -> 锁存当前代码约定的左转角速度符号
```

方向以当前已实车验证的 `Move_Z` 符号约定为准，不能同时反转 `Gray_Pos_mm[]` 和 `Move_Z` 公式。

#### `SHARP_TURN` 动作与退出

```text
Move_X = 0
Move_Z = 锁存方向 × 0.50 rad/s
```

该角速度沿用当前全白搜线的已知安全值，不使用普通巡线的 ±0.40 rad/s 限幅。退出条件为：中间区域重新见线，即 `black_count > 0` 且 `abs(raw) <= 12 mm` 连续 3 帧；退出后进入 `FOLLOW`，并从弯道速度 75 mm/s 起步。

保护条件：

- 转向累计达到一圈仍未重新居中：停车并保持故障状态，不允许无限转。
- 若进入 `SHARP_TURN` 后立即全白：保持同一锁存方向，转入 `LOST_SEARCH`，不能重新猜测方向。
- `black_count >= 4` 本身只触发弯道降速，**不能**单独触发急弯，避免宽黑线或交叉区域误判为发卡弯。

### 4.4 PI 状态切换保护

当前左右增量 PI 的 `Pwm` 与 `Last_bias` 是函数静态变量。进入或退出 `SHARP_TURN` / `LOST_SEARCH` 时，目标轮速会突变到零或反向，必须新增 `Speed_PI_Reset()`，清除左右 PI 的历史状态。

调用时机：

1. `FOLLOW -> SHARP_TURN`；
2. `SHARP_TURN -> FOLLOW`；
3. `FOLLOW/SHARP_TURN -> LOST_SEARCH`；
4. `LOST_SEARCH -> FOLLOW`；
5. 按键停车。

这是为避免旧 PWM 积累量在恢复前进时产生冲击；不改变正常 `FOLLOW` 状态中的 PI 参数。

## 5. 实施顺序

按下列提交拆分，任一步未通过都不进入下一步：

1. **观测提交**：增加状态、原始/滤波位置、黑线数、`Move_X`、`Move_Z` 的 OLED 或串口观测；不改变控制行为。
2. **直线稳定提交**：实现位置滤波、速度滞回与连续帧确认；只跑直线，保持 `GRAY_STEER_GAIN=1.70`。
3. **外环标定提交**：若直线仍为 S 形摆动，单次按 `1.70 -> 1.30 -> 1.00 -> 0.80` 下调 `GRAY_STEER_GAIN`，每次只测一个值；若转向不足，再反向小步调整。不得同时改变 PI、速度和增益。
4. **急弯提交**：实现 `SHARP_TURN` 与 PI 状态重置，先用单个左直角、单个右直角验证，再测试发卡弯。
5. **速度复测提交**：仅在所有方向、直线、左右直角、发卡弯连续通过后，评估是否提高 90/75 mm/s；每次只提高一个速度档。

## 6. 验收标准

### 直线

- 在 2 m 直线、90 mm/s 下连续跑 5 次，无明显周期性 S 形摆动、无 90/75 mm/s 高频来回切换。
- 中心压线时 `Move_Z` 仅在小范围波动，左右目标速度和实际速度不出现反复反向。
- 若摇摆仍存在，先看原始灰度位置是否跳变；原始位置稳定而 PWM/实际速度交替时，再按 PI 审计处理速度环。

### 直角与发卡

- 左、右各 5 次直角：均在正确方向进入 `SHARP_TURN`，重新居中后恢复前进，无反向误转。
- 左、右各 5 次发卡：不冲出弯外侧；若未在一圈内重新见线，安全停车而不是持续旋转。
- 宽黑线、普通圆弧不得错误进入 `SHARP_TURN`。
